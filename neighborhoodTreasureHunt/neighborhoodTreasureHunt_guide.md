# 우리동네 보물찾기 개발 가이드

## 1. 문서 목적

이 문서는 `우리동네 보물찾기 기획서.md`를 읽고 단일 HTML 게임으로 구현하는 과정을 설명합니다.
원본 방탈출 프로젝트의 흐름인 **기획서 작성 → AI 구현 → 브라우저 플레이 검증**을 우리동네 탐험 게임에 적용합니다.

## 2. 프로젝트 파일

```text
우리동네_보물찾기/
├─ 우리동네_보물찾기_안내.html      # 프로젝트 소개와 플레이 방법
├─ 우리동네_보물찾기 개발 가이드.md  # 이 문서
├─ 우리동네_보물찾기 기획서.md       # 게임 설계 원본
├─ 우리동네_보물찾기.html             # 완성된 단일 HTML 게임
└─ LLM-wiki.md                       # 설계 원칙·구현 기록·검증 기록
```

## 3. 구현 순서

### 1단계: 장면 만들기

- 16:9 비율의 동네 탐험 장면을 만든다.
- 하늘, 언덕, 집, 나무, 도로를 CSS로 구성한다.
- 외부 이미지 없이도 기본 화면이 보이도록 한다.

### 2단계: 핫스팟 배치

다음 오브젝트를 장면 위에 절대 위치로 배치합니다.

- 우체통
- 공원
- 도서관
- 빵집
- 보물상자

핫스팟은 semantic `button`으로 만들어 키보드와 모바일에서도 조작할 수 있도록 합니다.

### 3단계: 클릭 이벤트 연결

각 장소를 클릭했을 때 공통 모달 창을 열고 장소별 내용을 표시합니다.

```javascript
hotspots.forEach(hotspot => {
  hotspot.addEventListener('click', () => {
    handle(hotspot.dataset.place);
  });
});
```

### 4단계: 상태 관리

장소 해금과 퍼즐 해결 상태를 하나의 상태 객체로 관리합니다.

```javascript
const state = {
  unlocked: new Set(['mailbox']),
  solved: new Set(),
  clues: [],
  colorIndex: 0,
  gameOver: false,
  won: false
};
```

### 5단계: 퍼즐 구현

공원 퍼즐은 다음 색깔 순서를 사용합니다.

```text
파랑 → 노랑 → 빨강
```

틀리면 `gameOver()`를 호출하고, 모두 맞히면 도서관을 해금합니다.

### 6단계: 최종 암호 구현

최종 암호는 `317`입니다.
숫자 키패드로 세 자리 숫자를 입력하게 하고 정답이면 성공 오버레이를 표시합니다.

### 7단계: 재도전 구현

`reset()` 함수에서 다음 값을 초기화합니다.

- 해금 장소
- 해결 장소
- 수집 단서
- 퍼즐 진행 위치
- Game Over 상태
- 성공 상태

## 4. 배경 이미지 업로드

사용자가 이미지 파일을 선택하면 `FileReader`로 읽어 장면의 `background-image`에 적용합니다.
기본 CSS 배경은 그대로 유지하므로 이미지 없이도 게임을 실행할 수 있어야 합니다.

## 5. 브라우저 검증 체크리스트

- [ ] HTML 파일이 브라우저에서 열리는가?
- [ ] 동네 배경과 핫스팟이 표시되는가?
- [ ] 우체통을 클릭하면 첫 단서가 나오는가?
- [ ] 공원 색깔 퍼즐이 작동하는가?
- [ ] 정답 후 도서관이 해금되는가?
- [ ] 도서관과 빵집의 단서가 표시되는가?
- [ ] 보물상자 암호 입력이 작동하는가?
- [ ] 성공 엔딩이 표시되는가?
- [ ] 틀린 퍼즐에서 Game Over가 표시되는가?
- [ ] 재도전 후 초기 상태로 돌아가는가?
- [ ] 모바일 화면에서 버튼을 누르기 쉬운가?
- [ ] 브라우저 콘솔에 JavaScript 오류가 없는가?

## 6. 현재 검증 결과

2026-07-30 기준으로 다음 항목을 확인했습니다.

- JavaScript 문법 검사 통과
- 초기 화면 정상 표시
- 우체통 단서 획득 정상
- 색깔 퍼즐 정답 경로 정상
- 장소 순차 해금 정상
- 최종 암호 입력 성공 정상
- 성공 엔딩 정상
- 잘못된 색깔 선택 시 Game Over 정상
- 재도전으로 초기화 정상
- 브라우저 JavaScript 오류 없음

## 7. 수정할 때 주의할 점

- 장소를 추가할 때 `state.unlocked`와 `state.solved`의 흐름을 함께 수정합니다.
- 퍼즐 정답을 변경하면 빵집 단서와 보물상자 암호도 함께 변경합니다.
- 핫스팟 위치를 변경할 때 모바일 미디어쿼리 위치도 확인합니다.
- 외부 이미지나 CDN 없이도 기본 게임이 실행되는지 확인합니다.
- Game Over 후 재도전했을 때 모든 단서가 사라지는지 확인합니다.
