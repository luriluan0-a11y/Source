# 우리동네 보물찾기 게임 기획서

> 가족과 함께 동네를 탐험하며 단서를 모아 보물상자를 여는 웹 게임

## 1. 기본 정보

- 게임 제목: 우리동네 보물찾기
- 장르: 가족용 탐험·퍼즐 게임
- 형식: 단일 HTML 웹앱
- 플레이 방식: 장면 위의 장소 오브젝트를 클릭하고 단서를 모아 순서대로 퍼즐 해결
- 대상: 어린이·가족·AI 바이브코딩 체험 참가자

## 2. 시놉시스

어느 날 우리동네에 숨겨진 보물지도가 사라졌습니다.
동네 우체통에서 발견한 편지는 보물이 우리동네를 가장 잘 아는 사람에게만 모습을 보인다고 알려줍니다.
플레이어는 우체통, 공원, 도서관, 빵집을 차례로 탐험하며 단서를 모아 마지막 보물상자를 열어야 합니다.

## 3. 구현 지시문

//게임은 동네 배경 위에 장소 오브젝트를 핫스팟 버튼으로 배치하고, 각 오브젝트를 클릭하면 대화·단서·퍼즐이 실행되는 방식으로 구현한다.
//퍼즐을 해결한 장소만 다음 장소가 해금되도록 상태를 관리한다.
//기본 배경은 외부 이미지 없이도 실행되어야 하며, 사용자가 배경 이미지를 업로드하면 장면 배경으로 적용한다.
//단일 HTML 파일 안에 HTML·CSS·JavaScript를 모두 포함하고, 성공·실패·재도전 흐름을 구현한다.

## 4. 장소와 기능

| 순서 | 오브젝트 | 종류 | 내용 |
|---|---|---|---|
| 1 | 동네 우체통 | 대화·단서 | 편지를 보여주고 공원으로 안내한다. |
| 2 | 햇살 공원 | 퍼즐 | 파랑 → 노랑 → 빨강 색깔 순서를 맞힌다. |
| 3 | 작은 도서관 | 단서 | 책갈피에서 숫자 1을 발견한다. |
| 4 | 별빵집 | 단서 | 최종 암호 조합 3-1-7을 확인한다. |
| 5 | 보물상자 | 퍼즐 | 세 자리 암호를 입력해 성공 엔딩을 본다. |

## 5. 게임 상태 흐름

```text
우체통 조사
→ 공원 해금
→ 색깔 퍼즐 해결
→ 도서관 해금
→ 책갈피 숫자 확인
→ 빵집 해금
→ 최종 암호 확인
→ 보물상자 해금
→ 암호 317 입력
→ 성공 엔딩
```

## 6. 단서와 정답

- 첫 번째 단서: 공원 미끄럼틀 아래의 색깔 순서
- 색깔 퍼즐 정답: 파랑 → 노랑 → 빨강
- 두 번째 단서: 책갈피 숫자 1
- 세 번째 단서: 빵집 간판의 별 7개
- 최종 암호: 317

## 7. 실패 조건

- 색깔 퍼즐에서 순서를 틀린 경우
- 보물상자에 잘못된 암호를 입력한 경우

실패 시 다음 문구를 표시합니다.

> 아쉽지만 다시 도전해보세요. 단서를 다시 확인하고 천천히 풀어보세요.

재도전 버튼을 누르면 모든 장소와 퍼즐이 초기 상태로 돌아갑니다.

## 8. 성공 엔딩

> 축하합니다! 우리동네 곳곳의 단서를 모아 보물을 찾았습니다.
> 가족과 함께 동네를 천천히 관찰하면 평범한 하루도 멋진 모험이 됩니다.

## 9. UI 요구사항

- 장소 오브젝트는 움직이는 핫스팟으로 표시한다.
- 잠긴 장소는 흐리게 표시한다.
- 해결한 장소는 체크 표시와 초록색 상태로 표시한다.
- 현재 힌트 버튼을 제공한다.
- 진행률과 수집한 단서를 화면에 표시한다.
- 모바일에서도 장소를 쉽게 누를 수 있도록 한다.
- 사용자가 배경 이미지를 업로드할 수 있도록 한다.
