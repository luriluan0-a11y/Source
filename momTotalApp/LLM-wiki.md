# AI 엄마 사랑 종합 웹앱 (엄미새) 만들기 — LLM Wiki

> 경기공유학교 2026 · 가족과 함께하는 AI 바이브코딩 (유한대학교)
> Day08 · 2026.07.30

## 1. 개요

자녀와 가족이 AI(바이브코딩)의 도움을 받아 **엄마를 위한 세상에서 가장 특별한 감성 웹앱**을
직접 기획하고, 그 기획서를 AI IDE(Antigravity)에 입력하여 실제 동작하는 종합 서비스 웹앱으로
완성하는 특강 세션. 코딩 경험이 없는 참가자도 "기획서 작성기" 웹앱에서 엄마와의 당일치기 데이트 코스, 감동 선물 5가지, 그리고 엄마에게 물어볼 10가지 인생 질문만 채우면
자동으로 마크다운 기획서가 만들어지고, 이를 AI에게 전달하여 완벽한 앱을 생성하는 흐름이다.

## 2. 오늘의 목표

- 엄마와 함께 떠나는 **당일치기 힐링 데이트 코스**를 시각적 타임라인으로 기획한다.
- 엄마 만족도 200%의 **센스만점 선물 BEST 5**와 감동 메시지 카드를 구성한다.
- 엄마의 눈부신 청춘과 삶을 기록하는 **인생 10문 10답 인터뷰 카드**를 완성해본다.

## 3. 엄미새 앱 특화 설계 규칙

1. **따뜻하고 세련된 감성 UI**: 로즈 핑크, 샬롯 베이커, 크림 베이지 톤의 따뜻한 그래디언트와 은은한 Glassmorphism UI 연출.
2. **3대 핵심 모듈 탭 시스템**: [당일치기 데이트 코스] ➔ [감동 선물 BEST 5] ➔ [엄마 인생 10문 10답]으로 손쉽게 전환 가능한 인터랙티브 탭 네비게이션.
3. **감동 세레머니 & 편지 기능**: 질문 답변 입력 완료 시 하트 Canvas 파티클 이펙트와 엄마에게 전하는 감동 메시지 카드 발급.

## 4. 핵심 3대 모듈 구성 상세

| 모듈 | 주요 내용 | 세부 구성 |
|---|---|---|
| 🚗 당일치기 데이트 코스 | 엄마 취향저격 힐링 코스 | 09:00 감성 브런치 ➔ 11:30 수목원 산책 ➔ 14:00 다도/찻집 ➔ 17:00 온천 스파 & 정갈한 한정식 |
| 🎁 감동 선물 BEST 5 | 실용성과 감동을 동시에 잡은 선물 | ① 맞춤 건강검진/항노화 영양제 ② 효도 여행 쿠폰 ③ 실크 스카프/캐시미어 ④ 손편지 꽃상자 ⑤ 스마트 헬스케어 워치 |
| 💌 엄마 인생 10문 10답 | 엄마의 눈부신 이야기 기록 | ① 20대 가장 눈부셨던 꿈 ② 나를 태어났을 때 기분 ③ 가장 좋아하는 영화/노래 ④ 나에게 꼭 해주고 싶은 한 마디 등 |

## 5. 폴더 구성

```
momTotalApp/
├─ mom_guide.html              # 특강 진행용 안내 페이지 (오늘의 목표/3대모듈/순서)
├─ mom_paper.html              # 엄미새 웹앱 "기획서 작성기" 웹앱
├─ 엄마사랑_기획서.md           # 기획서 작성기로 만든 예시 기획서 (마크다운 결과물)
├─ mom_app.html                # 위 기획서를 AI가 구현한 완성 앱 (HTML 단일 페이지)
└─ LLM-wiki.md                 # 본 워크숍 종합 안내 위키 문서
```

## 6. 전체 제작 흐름 (참가자 관점)

1. **엄마 취향 파악하기** — 엄마가 좋아하는 데이트 장소, 받고 싶은 선물, 꼭 물어보고 싶었던 인생 질문 구상.
2. **기획서 작성기**(`mom_paper.html`)에서 원클릭 예시를 참고하여 데이트 타임라인, 선물 5선, 질문 10가지를 작성.
3. 작성 완료 후 **마크다운 파일 다운로드** (`.md`).
4. **Antigravity IDE**를 열고 "마크다운 기획서를 읽고 html 단일 페이지로 엄미새 종합 앱을 구현해줘." 라고 요청.
5. 완성된 **html 파일을 열어 엄마와 함께 직접 플레이하고 기록**해본다.

## 7. 기획서 작성기(`mom_paper.html`) 상세

바닐라 HTML/CSS/JS(프레임워크 없음, 단일 파일)로 구축된 폼 기반 도구.

### 7.1 주요 기능
- **예시대로 채우기 / 초기화**: 힐링 데이트, 감동 선물 5선, 인생 10문 10답 데이터를 원클릭으로 로딩.
- **기본 정보**: 앱 제목, 작성자(자녀 닉네임), 엄마 닉네임, 엄마에게 전하는 첫 인사말.
- **데이트 코스 설정**: 4단계 타임라인 (시간대, 장소명, 대표 활동, 엄마 맞춤 팁).
- **선물 5선 구성**: 선물명, 추천 이유, 감동 한 줄 편지.
- **인생 10문 10답 질문 구성**: 10가지 인터뷰 질문 및 가이드 문구.
- **마크다운 다운로드**: 입력 데이터를 조합하여 `# AI 엄미새 앱 기획서` 형식의 `.md` 다운로드.

### 7.2 생성되는 마크다운의 고정 지시문
다운로드되는 마크다운 맨 위에는 항상 다음 지시문이 주석(`//`)으로 포함되어, AI IDE가 구현 방식을 일관되게 적용하도록 유도한다.

```markdown
// 웹앱 구현 규칙:
// 1. [당일치기 데이트 코스], [감동 선물 5선], [엄마 인생 10문 10답] 3개 탭으로 전환되는 탭 UI를 구축해줘.
// 2. 10문 10답 질문마다 자녀와 엄마가 대답을 입력하고 보관할 수 있는 인터랙티브 대화 카드를 제작해줘.
// 3. 답변을 완성하거나 하트 버튼을 클릭하면 Canvas 분홍빛 하트 파티클 이펙트와 감동 편지 카드가 발급되도록 연출해줘.
```

## 8. 예시 기획서 & 완성 앱: "세상에서 가장 사랑하는 엄마를 위한 하루"

`mom_paper.html`의 "예시대로 채우기"로 생성된 기획서(`엄마사랑_기획서.md`)를 AI가 구현한 결과물이 `mom_app.html`이다.

### 8.1 구현 구조 (`mom_app.html`)
단일 HTML 파일, 프레임워크 없이 순수 JS 및 CSS Glassmorphism으로 구현.

- **상단 탭 바**: 🚗 당일치기 데이트 | 🎁 감동 선물 5선 | 💌 엄마 인생 10문 10답 | 💖 사랑의 메시지
- **데이트 코스 탭**: 타임라인 카드 및 엄마 취향 포인트 꿀팁 박스.
- **선물 5선 탭**: 5가지 센스 선물 3D 느낌 카드 & 선물 전달 팁.
- **10문 10답 탭**:
  - 10가지 질문 카드와 실시간 답변 입력 필드.
  - 답변 작성률 프로그레스 바.
  - 질문 완료 시 하트 Canvas 파티클 폭죽 세레머니.

## 9. 이 워크숍의 핵심 아이디어

- **엄마의 삶 기록 → 마크다운 다운로드 → AI 바이브코딩 → 감동 웹앱 선물** 워크플로우 적용.
- 단순 일회성 이벤트가 아닌 **엄마의 인생 이야기를 평생 보관하는 디지털 앨범** 역할 수행.
- 초보자도 부모님과의 따뜻한 추억을 디자인할 수 있도록 기획 템플릿화.
