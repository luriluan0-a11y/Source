# AI 롤플레이 시뮬레이션 앱 만들기 — LLM Wiki

> 경기공유학교 2026 · 가족과 함께하는 AI 바이브코딩 (유한대학교)
> Day06 · 2026.07.30

## 1. 개요

가족 단위 참가자가 AI(바이브코딩)의 도움을 받아 **나만의 AI 롤플레이 시뮬레이션 게임**을
직접 기획하고, 그 기획서를 AI IDE(Antigravity)에 입력하여 실제 동작하는 스토리 대화형 웹 게임으로
완성하는 특강 세션. 코딩 경험이 없는 참가자도 "기획서 작성기" 웹앱에서 역할, 세계관, NPC 대화 및 선택지만 채우면
자동으로 마크다운 기획서가 만들어지고, 이를 AI에게 전달하여 게임을 즉시 생성하는 흐름이다.

## 2. 오늘의 목표

- 플레이어가 선택하는 의사결정에 따라 이야기와 상태(체력, 에너토, 인벤토리)가 달라지는 롤플레이 게임을 만든다.
- SF 우주 탐사선 캡틴, 중세 왕국 명탐정, 사이버펑크 해커 등 다양한 테마와 서사를 기획해본다.
- NPC와의 긴장감 넘치는 대화, 분기 선택 시스템, 상태 스탯/인벤토리 관리, 멀티 엔딩 시스템을 구현해본다.

## 3. 롤플레이 시뮬레이션 특화 설계 규칙

1. **상황 몰입감(세계관 연출)**: 텍스트 기반 대화창과 캐릭터 일러스트/배경 이미지, 사운드 효과를 통해 플레이어가 캐릭터에 완전히 몰입하도록 연출한다.
2. **동적 스탯 & 인벤토리**: 플레이어의 선택에 따라 체력, 정신력, 에너토, 신용도 등의 스탯이 변화하고, 획득한 단서/아이템이 인벤토리에 기록된다.
3. **분기 선택지 & 멀티 엔딩**: 단순 일직선 스토리가 아닌, 선택에 따른 성패 분기 및 3가지 이상의 멀티 엔딩(성공, 실패, 딜레마 엔딩)을 배치한다.

## 4. 참고 시나리오 예시 (가족 추천 아이디어)

| 세계관 | 주요 역할 | 주요 목표 |
|---|---|---|
| SF 우주 탐사선 | 아스테리아호 캡틴 | 산소 결핍과 인공지능 오작동을 해결하고 미지의 행성에 안착하기 |
| 중세 미스터리 왕국 | 국왕의 수석 탐정 | 연회장에서 일어난 국왕 독살 시도 사건의 진범을 찾고 수수께끼 풀기 |
| 사이버펑크 2099 | 전설의 해커 '제로' | 거대 메가코프의 데이터베이스를 해킹하여 억울하게 갇힌 동료 구출하기 |
| 신비한 마법 학교 | 신입 마법사 수습생 | 금지된 서고의 마법책 분실 사건을 해결하고 최고의 마법사 졸업하기 |

## 5. 폴더 구성

```
AI롤플레이시뮬레이션/
├─ roleplay_guide.html         # 특강 진행용 안내 페이지 (오늘의 목표/시나리오/규칙/순서)
├─ roleplay_paper.html         # 롤플레이 시뮬레이션 "기획서 작성기" 웹앱
├─ 롤플레이_게임_기획서.md      # 기획서 작성기로 만든 예시 기획서 (마크다운 결과물)
├─ roleplay_game.html          # 위 기획서를 AI가 구현한 완성 게임 (HTML 단일 페이지)
└─ LLM-wiki.md                 # 본 워크숍 종합 안내 위키 문서
```

## 6. 전체 제작 흐름 (참가자 관점)

1. **세계관 및 주인공 역할 정하기** — 우주, 중세, 사이버펑크 등 흥미진진한 무대와 플레이어 역할 선정.
2. **기획서 작성기**(`roleplay_paper.html`)에서 원클릭 예시를 참고하여 배경, NPC 대화, 선택지 분기, 엔딩을 입력.
3. 작성 완료 후 **마크다운 파일 다운로드** (`.md`).
4. **Antigravity IDE**를 열고 "마크다운 기획서를 읽고 html 단일 페이지로 대화형 롤플레이 게임을 구현해줘." 라고 요청.
5. 완성된 **html 파일을 열어 가족과 함께 직접 플레이**해본다.

## 7. 기획서 작성기(`roleplay_paper.html`) 상세

바닐라 HTML/CSS/JS(프레임워크 없음, 단일 파일)로 구축된 폼 기반 도구.

### 7.1 주요 기능
- **예시대로 채우기 / 초기화**: 3가지 완성형 시나리오(SF 우주, 중세 탐정, 사이버펑크)를 원클릭으로 로딩.
- **기본 설정**: 게임 제목, 기획자, 주인공 이름/직업, 주요 목표, 실패 조건.
- **스탯 및 인벤토리**: 체력/에너지/신용도 기본값 및 시작 아이템 설정.
- **스토리 장면/선택지 구성**: 각 장면별 배경, NPC 대사, 선택지 2~3개(각 선택지별 스탯 변화 및 다음 장면 ID 지정).
- **마크다운 다운로드**: 입력 데이터를 조합하여 `# AI 롤플레이 시뮬레이션 게임 기획서` 형식의 `.md` 다운로드.

### 7.2 생성되는 마크다운의 고정 지시문
다운로드되는 마크다운 맨 위에는 항상 다음 지시문이 주석(`//`)으로 포함되어, AI IDE가 구현 방식을 일관되게 적용하도록 유도한다.

```markdown
// 게임 구현 규칙:
// 1. 스토리 장면별 대화창 UI와 플레이어 상태(체력, 에너지, 인벤토리)를 실시간 HUD로 표시해줘.
// 2. 플레이어의 선택지에 따라 스탯 변화, 아이템 획득 및 다음 장면으로 이동하도록 분기 로직을 구성해줘.
// 3. 목표 달성 시 성공 엔딩(Canvas 축하 효과), 체력 0 또는 조건 미달 시 실패 엔딩 화면을 시각화해줘.
```

## 8. 예시 기획서 & 완성 게임: "아스테리아호의 위기"

`roleplay_paper.html`의 "예시대로 채우기"로 생성된 기획서(`롤플레이_게임_기획서.md`)를 AI가 구현한 결과물이 `roleplay_game.html`이다.

### 8.1 구현 구조 (`roleplay_game.html`)
단일 HTML 파일, 프레임워크 없이 순수 JS 및 CSS Glassmorphism UI로 구현.

- **HUD 인터페이스**: 상단 체력(HP), 에너토(Energy), 신뢰도(Trust) 게이지 및 소지품 인벤토리 슬롯.
- **스토리 대화 화면**: NPC 아바타 초상화, 타이핑 텍스트 연출, 긴장감 있는 배경 그래픽.
- **인터랙티브 선택지**: 2~3개의 반응형 선택지 버튼 (선택 시 스탯 변동 애니메이션 및 사운드 효과).
- **엔딩 연출**:
  - **성공 엔딩**: 미션 성공 메시지 + Canvas 승리 파티클 세레머니.
  - **실패 엔딩**: 산소 고갈/시스템 파괴 실패 화면 및 재도전 버튼.

## 9. 이 워크숍의 핵심 아이디어

- **스토리보드 기획 → 마크다운 다운로드 → AI 바이브코딩 → 인터랙티브 RPG 시뮬레이션 실행** 워크플로우 적용.
- 선택지에 따른 **상태 값 변화와 아이템 시스템**을 통해 게임적 재미와 의사결정 의의 극대화.
- 초보자도 손쉽게 자신만의 웹 소설/텍스트 어드벤처 게임을 완성할 수 있도록 템플릿화.
