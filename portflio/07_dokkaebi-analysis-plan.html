1직업 없는 스킬 조합: 직업의 빈자리를 어떻게 채우는가

문제 정의

표 1. 직업이 하던 역할과 직업이 없을 때 생길 수 있는 문제
직업이 하던 역할직업이 없을 때 생길 수 있는 문제
캐릭터 정체성 ("나는 궁수다")내 캐릭터를 설명할 말이 없다
파티 역할 분담 (탱커·딜러·힐러)파티를 짤 기준이 없거나, 모두 같은 딜러가 된다
성장 방향 안내무엇을 키워야 할지 몰라 헤맨다
다양성 보장 (직업마다 플레이가 다름)강한 조합 하나로 쏠리면 모든 캐릭터가 같아진다

확인할 것

  1. 스타일이 사실상 직업 역할을 하는가? 12개 스타일(근거리·원거리·유틸)이 탱커·딜러·지원으로 나뉘는가, 모두 딜러인가?
  2. 정체성을 무엇으로 대신하는가? 필살기 연출, 칭호, 외형(꾸미기), 스타일 숙련도 표시 등
  3. 파티·문파 콘텐츠가 역할을 요구하는가? 보스·문파전에서 특정 역할이 없으면 막히는가?
  4. 빌드를 바꾸는 비용은 얼마인가? 계열별 강화 재화 분리, 상시 초기화 없음이 "자유로운 조합"과 충돌하는지
  5. 실제로 빌드가 쏠리는가? 커뮤니티 추천 빌드·티어표가 몇 개 조합에 몰려 있는가

조사 방법

  • 직접 플레이: 근거리·원거리·유틸 스타일을 1개 이상씩 같은 구간에서 써 보고 체감 차이 기록
  • 커뮤니티 빌드 수집: 공식 커뮤니티·유튜브 공략의 추천 조합을 모아 상위 조합 비중 계산
  • 콘텐츠별 비교: 사냥 / 보스 / 문파전에서 추천 조합이 달라지는지 확인

판단 기준

표 2. 직업 없는 구조를 잘 풀었는지 판단하는 신호
잘 풀었다는 신호못 풀었다는 신호
콘텐츠마다 추천 조합이 다르다모든 콘텐츠에서 같은 조합이 추천된다
파티에서 서로 다른 역할이 필요하다파티 구성 기준이 전투력뿐이다
빌드 변경 비용이 시도할 만한 수준이다한 번 정하면 바꾸기 어려워 "정답 빌드"만 따라간다

2문파·커뮤니티: 장기 플레이를 받쳐 주는가

확인할 것

  1. 문파 가입 유도: 언제, 어떻게 안내하는가? 신규 유저가 문파를 찾기 쉬운가?
  2. 문파가 필요한 이유: 문파에서만 얻는 보상·도술은? 문파 없이도 성장에 지장이 없는가?
  3. 소통 도구: 문파 채팅, 게시판, 출석, 공동 목표 같은 장치가 있는가?
  4. 분신 자동 참여의 영향: 소속감을 유지시키는가, 직접 만나 플레이할 이유를 줄이는가?
  5. 경쟁 구조: 신기 쟁탈전·차원 점령전이 상위 문파만의 콘텐츠인가, 중소 문파도 참여 동기가 있는가?
  6. 게임 밖 커뮤니티: 공식 커뮤니티, 디스코드, 유튜브 공략 채널이 얼마나 활발한가?

조사 방법

표 3. 커뮤니티 활성화 측정 데이터와 수집 주기
데이터수집 방법주기
문파 모집글 수게임 내 모집 게시판, 공식 커뮤니티 모집 게시판주 1회
공식 커뮤니티 게시글 수·주요 주제공식 커뮤니티 게시판주 1회
앱 리뷰 키워드구글 플레이·앱스토어 최신 리뷰의 "문파", "길드", "혼자" 등 언급주 1회
문파 내 활동가입한 문파의 접속 인원, 채팅 빈도플레이할 때마다
커뮤니티 활성화는 한 번 보고 판단할 수 없다. 최소 2~4주 같은 기준으로 기록해 추세를 본다.

판단 기준

표 4. 커뮤니티 활성화와 침체를 가르는 신호
활성화 신호침체 신호
모집글·게시글이 유지되거나 늘어난다출시 직후 이후 계속 줄어든다
문파 활동 이야기(공략, 문파전 후기)가 많다불만·접는다는 글 비중이 커진다
중소 문파도 참여할 콘텐츠가 있다상위 문파만 보상을 독점한다

3재화 부족과 과금: 정체 구간을 어떻게 매출로 연결하는가

확인할 것

  1. 만렙 이후 필요한 재화: 엽전, 요혼석, 영웅 등급 이후 제작 재료 등 무엇이 얼마나 필요한가?
  2. 무과금 수급량: 하루에 플레이로 얻는 양은 얼마인가?
  3. 부족분의 판매 방식: 상점·패키지로 파는가? 가격은 얼마인가?
  4. 노출 시점: 만렙 도달 직후, 강화 직후처럼 재화가 부족한 순간에 상품이 뜨는가?
  5. 거래소 구조: 플레이 재화("금전")로 돌아가는 거래소는 유료 재화와 어떻게 연결되는가?
  6. 운영 조정: 재화 수급량 상향 뒤 판매 상품이나 성장 속도가 어떻게 바뀌었는가?
  7. "낮은 과금 압박" 평가와 맞는가? 능력치 없는 꾸미기와 성장 재화 판매가 어떻게 공존하는가?

조사 방법: 재화별 무과금 vs 과금 비교

표 5. 재화별 비교표 양식 (플레이하며 직접 측정한 값만 채운다)
재화용도1단계 성장 필요량하루 무과금 획득량무과금 소요일판매 상품·가격과금 시 단축 일수
(예: 요혼석)
  • 패키지 상품은 운빨존많겜 과금 정리와 같은 형식(상품명·가격·구성·구매 제한·홍보 문구)으로 따로 기록한다.
  • 모바일인덱스 순위 기록에서 매출 순위 변화와 업데이트·이벤트 시점을 겹쳐 본다.

판단 기준

표 6. 정체 구간과 과금 연결 정도를 판단하는 신호
정체 구간을 과금으로 연결하는 신호과금 압박이 낮다는 신호
무과금 소요일이 길고, 과금하면 크게 줄어든다무과금으로도 감당할 만한 기간이다
재화 부족 순간에 맞춰 상품이 노출된다상품 노출이 성장 흐름과 따로 논다
문파전 보상이 전투력 차이로 갈린다경쟁 결과가 협동·전략에 더 좌우된다

세 축의 연결 (가설)

아래는 확인 전 가설이다. 조사 결과로 맞는지 판정한다.

  1. 빌드 쏠림 → 재빌드 비용 → 과금
    강한 조합으로 쏠리면 빌드를 바꾸고 싶어진다. 계열별 재화가 나뉘어 있으면 다시 키우는 비용이 과금 수요가 된다.
  2. 문파 경쟁 → 성장 압박 → 과금
    문파전에서 이기려면 전투력이 필요하다. 정체 구간에서 전투력을 올릴 방법이 과금뿐이라면 경쟁이 결제를 이끈다.
  3. 문파 소속감 → 이탈 방지
    정체 구간에서 결제하지 않는 유저를 붙잡는 것은 문파 관계일 수 있다. 커뮤니티가 약하면 정체 구간이 곧 이탈 구간이 된다.

진행 순서

1단계만렙(50)까지 플레이, 스타일 3개 이상 체험, 문파 가입산출물: 플레이 기록, 스타일 비교표
2단계만렙 이후 재화 수급량·필요량 측정, 상점·패키지 기록산출물: 재화 비교표, 과금 상품 정리
3단계2~4주 동안 커뮤니티·리뷰·순위 주간 기록산출물: 주간 기록표
4단계세 축의 결과로 가설 판정, 개선 제안 작성산출물: 분석 보고서

작성할 때 지킬 것

  • 표·이미지 설명, 페이지 번호, 한 글자 줄바꿈 점검, 개요체로 쓰기
  • 직접 확인한 사실, 기사·회사 발표 내용, 내 추론을 구분한다. 기사·발표 내용에는 출처를 단다.
  • 결론은 "그래서 무엇을 고쳐야 하는가"까지 간다. 개선 제안에는 근거 데이터를 붙인다.
