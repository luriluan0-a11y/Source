# AI 타이쿤 / 경영 시뮬레이션 앱 만들기 — LLM Wiki

> 경기공유학교 2026 · 가족과 함께하는 AI 바이브코딩 (유한대학교)
> Day07 · 2026.07.30

## 1. 개요

가족 단위 참가자가 AI(바이브코딩)의 도움을 받아 **나만의 AI 타이쿤 경영 시뮬레이션 게임**을
직접 기획하고, 그 기획서를 AI IDE(Antigravity)에 입력하여 실제 동작하는 경영 시뮬레이션 웹 게임으로
완성하는 특강 세션. 코딩 경험이 없는 참가자도 "기획서 작성기" 웹앱에서 가게 이름, 메뉴 가격, 재료비, 돌발 이벤트를 채우면
자동으로 마크다운 기획서가 만들어지고, 이를 AI에게 전달하여 게임을 즉시 생성하는 흐름이다.

## 2. 오늘의 목표

- 재료 준비, 가격 설정, 손님 서빙, 영업 정산을 경험하는 경영 타이쿤 게임을 만든다.
- 디저트 카페, 우주 푸드트럭, 고양이 베이커리 등 나만의 차별화된 상점 컨셉을 기획해본다.
- 손님 유입 서빙 시스템, 1일 영업 정산 리포트, 돌발 경영 이벤트 모달, 최종 7일 목표 달성 엔딩을 구현해본다.

## 3. 타이쿤 시뮬레이션 특화 설계 규칙

1. **상점 경영 루프**: [아침 재료 준비 & 가격 설정] ➔ [낮 영업시간 손님 서빙] ➔ [저녁 1일 정산 리포트]로 이어지는 명확한 일일 경영 루프 제공.
2. **손님 반응 & 콤보 서빙**: 주문에 맞는 메뉴를 빠르게 클릭해 서빙하면 연속 콤보 보너스와 가게 평점(★)이 상승.
3. **돌발 경영 이벤트**: 파워 블로거 방문, 재료 조기 소진, 비 오는 날 등 매출과 평점에 영향을 주는 선택지 모달 배치.

## 5. 폴더 구성

```
AIticoon/

├─ tycoon_paper.html          # 타이쿤 시뮬레이션 "기획서 작성기" 웹앱
├─ 타이쿤_게임_기획서.md       # 기획서 작성기로 만든 예시 기획서 (마크다운 결과물)
├─ tycoon_game.html           # 위 기획서를 AI가 구현한 완성 게임 (HTML 단일 페이지)

```

## 6. 전체 제작 흐름 (참가자 관점)

1. **가게 컨셉 및 메뉴 정하기** — 디저트 카페, 푸드트럭, 베이커리 등 내가 경영하고 싶은 상점 선택.
2. **기획서 작성기**(`tycoon_paper.html`)에서 원클릭 예시를 참고하여 메뉴 이름, 재료비, 판매가, 돌발 이벤트를 입력.
3. 작성 완료 후 **마크다운 파일 다운로드** (`.md`).
4. **Antigravity IDE**를 열고 "마크다운 기획서를 읽고 html 단일 페이지로 타이쿤 경영 게임을 구현해줘." 라고 요청.
5. 완성된 **html 파일을 열어 가족과 함께 직접 플레이**해본다.

## 7. 기획서 작성기(`tycoon_paper.html`) 상세

바닐라 HTML/CSS/JS(프레임워크 없음, 단일 파일)로 구축된 폼 기반 도구.

### 7.1 주요 기능
- **예시대로 채우기 / 초기화**: 3가지 테마(디저트 카페, 우주 푸드트럭, 고양이 베이커리)를 원클릭으로 로딩.
- **기본 정보**: 가게 이름, 사장님 닉네임, 시작 자금, 목표 금액, 총 영업일 수 (7일).
- **메뉴 카드 설정**: 메뉴명, 재료비, 판매가, 인기 지수, 메뉴 이미지 URL.
- **돌발 이벤트 구성**: 이벤트명, 발생 상황, 선택지 2가지 (비용/평점 영향).
- **마크다운 다운로드**: 입력 데이터를 조합하여 `# AI 타이쿤 경영 게임 기획서` 형식의 `.md` 다운로드.

### 7.2 생성되는 마크다운의 고정 지시문
다운로드되는 마크다운 맨 위에는 항상 다음 지시문이 주석(`//`)으로 포함되어, AI IDE가 구현 방식을 일관되게 적용하도록 유도한다.

```markdown
// 게임 구현 규칙:
// 1. [재료 구매/가격 설정] -> [영업 시간 손님 서빙] -> [1일 매출 정산 리포트]의 1일 경영 루프를 구축해줘.
// 2. 손님 캐릭터의 주문 아이콘을 클릭하여 서빙하는 실시간 서빙 UI와 돌발 경영 이벤트 모달을 구현해줘.
// 3. 7일차 영업 종료 후 최종 목표 금액 달성 여부에 따라 우승 세레머니(Canvas 폭죽) 및 사장님 랭킹을 시각화해줘.
```

## 8. 예시 기획서 & 완성 게임: "달콤 포근 디저트 카페 7일 경영"

`tycoon_paper.html`의 "예시대로 채우기"로 생성된 기획서(`타이쿤_게임_기획서.md`)를 AI가 구현한 결과물이 `tycoon_game.html`이다.

### 8.1 구현 구조 (`tycoon_game.html`)
단일 HTML 파일, 프레임워크 없이 순수 JS 및 CSS 애니메이션으로 구현.

- **HUD 네비게이션**: DAY (1/7일차), 보유 자금(Gold), 카페 평점(★ 4.8), 재고 상황.
- **아침 재료 준비 모달**: 각 메뉴별 재료 재고 구매 & 단가 설정.
- **낮 영업 시간 화면**:
  - 카운터로 걸어오는 손님 애니메이션.
  - 말풍선 주문 아이콘 클릭 서빙 ➔ 콤보 팝업 & Gold 획득 애니메이션.
  - 돌발 마케팅/날씨 이벤트 팝업.
- **저녁 1일 정산 리포트**: 오늘 총 매출, 재료비 지출, 순이익, 평점 변화, 하루 회고 일기.
- **7일차 최종 엔딩**: 목표 매출 달성 시 백만장자 트로피 & Canvas Confetti 폭죽 효과.

## 9. 이 워크숍의 핵심 아이디어

- **상점 기획 → 마크다운 다운로드 → AI 바이브코딩 → 인터랙티브 타이쿤 게임 실행** 워크플로우 적용.
- 손님 서빙의 **순발력 타격감**과 **경제적인 재고/가격 설정**의 결합을 통해 게임적 재미 극대화.
- 초보자도 쉽게 나만의 상점 경영 일지를 완성할 수 있도록 템플릿화.
