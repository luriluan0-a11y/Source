# 블로그 키워드 분석기

절약을 관심사로 두고, **절약을 위해 필요한 마인드와 실천 과제**를 주제로 블로그 글감을 뽑는 로컬 도구입니다.

## 기능

- 절약 관련 키워드 확장
- 독자 검색 의도 분류
- 키워드 점수화
- 제목 후보 생성
- 글 구성 추천
- 마크다운 보고서 저장

## 실행 방법

```bash
cd "/c/Users/luril/OneDrive - 유한대학교/연구/Luke_Obsidion/10_working/blog_keyword_analyzer"
python blog_keyword_analyzer.py --theme "절약 마인드" --top 10
```

## 결과 파일 위치 지정

```bash
python blog_keyword_analyzer.py --theme "절약 실천 과제" --top 12 --out "절약_키워드_분석.md"
```

## 추천 사용 흐름

1. 큰 주제 입력
   - 예: 절약
   - 예: 절약 마인드
   - 예: 식비 절약
   - 예: 고정비 줄이기

2. 상위 키워드 확인

3. 가장 점수가 높은 키워드로 첫 글 작성

4. 보고서의 제목 후보와 글 구성을 활용
