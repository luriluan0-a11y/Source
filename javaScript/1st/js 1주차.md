# 자바스크립트 기초 1주차

> 식별자, 문장, 데이터 타입, 변수, 조건문, 반복문, break/continue

## 1. 자바스크립트 식별자

- 자바스크립트 프로그램의 변수, 상수(리터럴), 함수의 이름

### 식별자 만드는 규칙

- 첫 번째 문자: 알파벳(A-Z, a-z), 언더스코어(`_`), `$` 문자만 사용 가능
- 두 번째 이상 문자: 알파벳, 언더스코어, 0-9, `$` 사용 가능
- 대소문자는 구분되어 다루어짐 → `myHome`과 `myhome`은 다른 식별자
- 자바스크립트 예약어 사용 불가 → `false`, `for`, `if`, `null` 등

### 식별자 사용 사례

```js
6variable;      // (X) 숫자로 시작할 수 없음
student_ID;     // (O)
_code;          // (O) 문법적으로는 맞지만 관례상 권장하지 않음
if;             // (X) 예약어 if는 사용 불가
%calc;          // (X) % 사용 불가
bar, Bar;       // (O) bar와 Bar는 서로 다른 식별자임에 주의
```

> 실무 팁: 언더스코어로 시작하는 이름(`_code`)은 보통 "내부에서만 쓰는 값"이라는 관례적 표시로 쓰입니다. 특별한 이유가 없다면 일반 변수명을 사용합니다.

## 2. 자바스크립트 문장

자바스크립트 프로그램의 기본 단위는 문장이며, 문장과 문장을 구분하기 위해 세미콜론(`;`)을 사용합니다.

```js
i = i + 1               // (O) 한 줄에 한 문장만 있는 경우 세미콜론 생략 가능
j = j + 1;               // (O)
k = k + 1; m = m + 1;    // (O) 한 줄에 여러 문장
n = n + 1  p = p + 1;    // (X) 첫 번째 문장 끝에 세미콜론이 필요함
```

한 줄에 한 문장만 쓸 경우 세미콜론은 생략 가능하지만, 습관적으로 붙이는 것을 권장합니다. 한 줄에 여러 문장을 쓸 때는 세미콜론이 반드시 필요합니다.

### 주석문

```js
// 한 라인 주석. 라인의 끝까지 주석 처리

/*
  여러 라인 주석
  별표-슬래시로 닫아준다
*/
```

## 3. 데이터 타입

자바스크립트 언어에서 다루는 데이터 종류는 다음과 같습니다.

| 타입 | 설명 | 예시 |
|---|---|---|
| 숫자 | 정수, 실수를 구분하지 않고 하나의 타입으로 다룸 | `42`, `3.14` |
| 논리 | 참, 거짓 | `true`, `false` |
| 문자열 | 따옴표로 감싼 문자의 나열 | `'좋은 세상'`, `"a"`, `"365"` |
| 객체 레퍼런스 | 객체를 가리킴. C 언어의 포인터와 유사 | `{ name: '루크' }` |
| null | 값이 없음을 표시하는 특수 키워드. `Null`, `NULL`과는 다름 | `null` |

> 특징: 자바스크립트에는 문자(character) 타입이 없습니다. `"a"`처럼 글자 하나도 문자열로 표현합니다.

## 4. 변수

- 변수: 자바스크립트 데이터 저장 공간
- 변수 선언: 변수 이름을 정하고, 저장 공간을 할당하는 것

### 변수 선언 방법: var, let, const

| 키워드 | 특징 |
|---|---|
| `var` | 가장 오래된 방식. 재선언·재할당 모두 가능하며 범위(scope) 규칙이 느슨해 오류가 생기기 쉬움. 요즘은 잘 사용하지 않음 |
| `let` | 값을 바꿀 수 있는 변수 선언. 재선언 불가, 재할당은 가능 |
| `const` | 값이 변하지 않는 상수 선언. 선언과 동시에 반드시 초기화, 재할당 불가 |

```js
let score = 0;         // 값이 바뀔 수 있는 변수
score = 10;             // 재할당 가능

const PI = 3.14;        // 값이 고정된 상수
PI = 3.141592;           // (X) 오류 발생: const는 재할당 불가
```

> 기본 원칙: 가급적 `const`를 사용하고, 값이 바뀌어야 할 때만 `let`을 사용합니다. `var`는 특별한 이유가 없다면 사용하지 않습니다.

## 5. 조건문

조건에 따라 실행 흐름을 분기합니다.

### if문 / if-else문

```js
let hp = 30;

if (hp <= 0) {
  console.log("게임 오버");
} else if (hp < 50) {
  console.log("체력이 위험합니다");
} else {
  console.log("체력이 충분합니다");
}
```

### switch문

하나의 값을 여러 경우와 비교해서 분기가 많을 때는 switch문이 if-else보다 읽기 편합니다.

```js
let stage = 2;

switch (stage) {
  case 1:
    console.log("튜토리얼");
    break;
  case 2:
    console.log("초급 던전");
    break;
  default:
    console.log("알 수 없는 스테이지");
}
```

> 주의: switch문에서 `break`를 빠뜨리면 아래 case문이 조건과 상관없이 계속 실행됩니다(fall-through). 각 case가 끝날 때 `break`를 잊지 않아야 합니다.

## 6. 반복문

조건이 만족되는 동안 같은 코드 블록을 반복해서 실행합니다.

### for문 — 반복 횟수가 정해져 있을 때

```js
// 초기값; 조건식; 증감식
for (let i = 0; i < 5; i++) {
  console.log("반복 " + i + "번째");
}
```

### while문 — 조건을 먼저 검사, 반복 횟수를 미리 알 수 없을 때

```js
let hp = 100;

while (hp > 0) {
  hp -= 20;
  console.log("남은 체력: " + hp);
}
```

### do-while문 — 조건과 상관없이 최소 한 번은 실행

```js
let count = 0;

do {
  console.log("count: " + count);
  count++;
} while (count < 3);
```

| 구문 | 언제 사용하나 |
|---|---|
| `for` | 반복 횟수가 정해진 경우 |
| `while` | 조건에 따라 반복 횟수가 유동적인 경우, 최소 0번 실행될 수 있음 |
| `do-while` | 조건과 무관하게 최소 1번은 반드시 실행해야 하는 경우 |

## 7. break 문과 continue 문

### break — 반복을 즉시 종료

```js
for (let i = 0; i < 10; i++) {
  if (i === 5) {
    break;  // i가 5가 되는 순간 반복문을 완전히 빠져나감
  }
  console.log(i);
}
// 출력: 0 1 2 3 4
```

### continue — 이번 반복만 건너뛰기

```js
for (let i = 0; i < 5; i++) {
  if (i === 2) {
    continue;  // i가 2일 때만 건너뛰고 다음 반복으로 이동
  }
  console.log(i);
}
// 출력: 0 1 3 4
```

> `break`는 반복문 자체를 끝내고, `continue`는 현재 반복만 건너뛰고 다음 반복으로 넘어갑니다.
