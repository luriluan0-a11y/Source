1let / const 재할당 비교

let과 const로 각각 변수를 선언하고, 왜 하나는 값을 바꿀 수 있고 다른 하나는 안 되는지 확인합니다.

let score = 0;
score = 10;                // (O) let은 재할당 가능

const PI = 3.14;
// PI = 3.141592;          // (X) TypeError: Assignment to constant variable.

21부터 10까지의 합

    
for문을 이용해 1부터 10까지의 합을 구합니다.

    
let sum = 0;
for (let i = 1; i <= 10; i++) {
  sum += i;
}

    
RESULT

    

  


  

    
31~20 중 짝수만 출력 (continue)

    
홀수를 만나면 continue로 건너뛰고, 짝수만 출력합니다.

    
for (let i = 1; i <= 20; i++) {
  if (i % 2 !== 0) {
    continue;
  }
  console.log(i);
}

    
RESULT

    

  


  

    
4처음 만나는 7의 배수 (break)

    
1부터 반복하다가 처음 7의 배수를 만나면 그 숫자를 출력하고 반복을 멈춥니다.

    
for (let i = 1; i <= 100; i++) {
  if (i % 7 === 0) {
    console.log(i);
    break;
  }
}
