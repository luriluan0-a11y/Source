브라우저 모델(BOM)과 문서 모델(DOM)

자바스크립트가 브라우저 창과 웹 페이지를 어떻게 객체로 다루는지 익힙니다

🗺️

먼저 큰 그림부터

브라우저가 자바스크립트에 제공하는 두 개의 객체 묶음

브라우저에서 실행되는 자바스크립트는 언어 자체의 문법(1주차 내용) 외에, 브라우저가 미리 만들어 둔 객체들을 사용할 수 있습니다. 이 객체들은 크게 두 갈래로 나눌 수 있습니다.

BOM

Browser Object Model · 브라우저 객체 모델. 브라우저 창 자체를 제어합니다. 주소 이동, 창 열기/닫기, 화면 크기, 방문 기록, 브라우저 정보 등.

DOM

Document Object Model · 문서 객체 모델. 현재 열려 있는 웹 페이지(HTML 문서)의 내용을 제어합니다. 요소 찾기, 텍스트 바꾸기, 태그 추가/삭제, 스타일 변경 등.

window (최상위 전역 객체 · BOM의 중심) ├─ location 현재 URL, 페이지 이동 ├─ history 앞으로 / 뒤로 가기 ├─ navigator 브라우저·OS 정보 ├─ screen 모니터 해상도 ├─ console 개발자 도구 콘솔 └─ document ← 여기서부터가 DOM (열려 있는 HTML 문서) ├─ html │ ├─ head │ └─ body │ ├─ h1 │ └─ p ...
핵심 — window는 브라우저 안 모든 것의 최상위 객체입니다. document는 그 window가 가진 여러 자식 중 하나이며, "화면에 보이는 문서"를 담당합니다. 그래서 window.document이지만 window.은 생략할 수 있어 그냥 document라고 씁니다.
🌐

브라우저 객체 모델 (BOM)

브라우저 창을 다루는 객체들

BOM은 특정 표준으로 완전히 통일되어 있지는 않지만, 모든 브라우저가 거의 동일하게 지원하는 객체들이 있습니다. 모두 window의 하위 객체입니다.

객체담당대표 멤버
window브라우저 창 전체, 전역 스코프alert(), setTimeout(), innerWidth
location현재 페이지의 주소(URL)href, reload(), assign()
history방문 기록(뒤로/앞으로)back(), forward(), go()
navigator브라우저·기기 정보userAgent, language, onLine
screen사용자 모니터 정보width, height
document현재 열린 HTML 문서 (= DOM)getElementById(), querySelector()
🪟

window 객체

모든 전역 코드가 살고 있는 집

전역으로 선언한 함수나 var 변수, alert 같은 내장 함수는 모두 window의 속성입니다. 그래서 window.alert("안녕")과 alert("안녕")은 완전히 같습니다.

대화상자 메서드

EXAMPLE
alert("저장되었습니다.");            // 확인 버튼만 있는 알림창

const ok = confirm("정말 삭제할까요?"); // 확인/취소 → true 또는 false 반환
if (ok) {
  console.log("삭제 진행");
}

const name = prompt("이름을 입력하세요", "루크"); // 입력창 → 입력한 문자열(또는 null) 반환
console.log("환영합니다, " + name);

타이머 메서드

EXAMPLE
// 2초 뒤에 한 번 실행
setTimeout(function () {
  console.log("2초 지났습니다");
}, 2000);

// 1초마다 반복 실행
const id = setInterval(function () {
  console.log("1초마다 실행");
}, 1000);

// 반복 중지
clearInterval(id);

창 제어 & 크기

멤버설명
window.open(url)새 창(또는 탭)을 연다
window.close()스크립트로 연 창을 닫는다
window.innerWidth / innerHeight내용이 보이는 영역의 가로·세로 픽셀
window.scrollTo(x, y)지정한 좌표로 스크롤 이동
주의 — alert, confirm, prompt는 창이 떠 있는 동안 코드 실행과 페이지 조작이 모두 멈춥니다(동기 방식). 실제 서비스에서는 잘 쓰지 않고, 학습·디버깅 용도로 이해하면 됩니다.
🧭

location · history 객체

주소를 읽고, 페이지를 이동한다

location — 현재 URL

EXAMPLE
console.log(location.href);      // 전체 주소: https://yu.ac.kr/board?page=2
console.log(location.protocol); // "https:"
console.log(location.host);     // "yu.ac.kr"
console.log(location.pathname); // "/board"
console.log(location.search);   // "?page=2"

location.href = "https://yu.ac.kr";  // 해당 주소로 이동
location.reload();                    // 새로고침(F5)
location.assign("/login");            // 이동 (뒤로가기 기록 남음)
location.replace("/login");           // 이동 (현재 기록을 덮어씀)

history — 방문 기록

EXAMPLE
history.back();     // 뒤로 가기 (브라우저 ← 버튼과 동일)
history.forward();  // 앞으로 가기
history.go(-2);     // 2단계 뒤로
console.log(history.length); // 현재 탭의 기록 개수
보안 참고 — history로는 "몇 단계 이동"만 할 수 있고, 사용자가 어떤 사이트를 방문했는지 목록을 읽을 수는 없습니다. 개인정보 보호를 위한 제한입니다.
💻

navigator · screen 객체

브라우저와 화면 환경을 알아낸다
EXAMPLE
// navigator — 브라우저 / 기기 정보
console.log(navigator.userAgent);  // 브라우저 종류·버전 문자열
console.log(navigator.language);   // "ko-KR"
console.log(navigator.onLine);     // 온라인 여부 true / false

// screen — 사용자 모니터 정보
console.log(screen.width, screen.height);  // 예: 1920 1080
console.log(screen.availWidth);            // 작업 표시줄을 뺀 사용 가능 너비
window.innerWidth는 브라우저 창 크기, screen.width는 모니터 전체 크기입니다. 반응형 판단에는 보통 window.innerWidth를 씁니다.
🌳

문서 객체 모델 (DOM)

HTML 문서를 나무 모양 객체로

브라우저는 HTML 문서를 읽어들이면서 각 태그를 객체(노드)로 바꾸고, 태그의 포함 관계를 그대로 트리 구조로 만듭니다. 이 트리 전체가 DOM이고, 자바스크립트는 이 트리를 탐색·수정해서 화면을 바꿉니다.

원본 HTML

<body> <h1>공지</h1> <p class="msg">안녕하세요</p> </body>

DOM 트리

body ├─ h1 │ └─ "공지" (텍스트 노드) └─ p.msg └─ "안녕하세요"

노드의 종류

  • 요소 노드(element) — <div>, <p> 같은 태그
  • 텍스트 노드(text) — 태그 사이의 글자
  • 속성 노드(attribute) — class="msg", id="title" 같은 속성
  • 문서 노드(document) — 트리의 뿌리, document 그 자체

탐색용 속성

속성가리키는 것
parentElement부모 요소
children자식 요소들의 목록
firstElementChild / lastElementChild첫 번째 / 마지막 자식 요소
nextElementSibling / previousElementSibling다음 / 이전 형제 요소
🎯

요소 선택하기

트리에서 원하는 노드를 찾아온다

DOM을 조작하려면 먼저 대상 요소를 변수로 가져와야 합니다. 가장 많이 쓰는 방법은 querySelector 계열입니다.

메서드반환설명
getElementById("id")요소 1개id로 찾기. 가장 빠름
querySelector("CSS선택자")요소 1개조건에 맞는 첫 번째 요소
querySelectorAll("CSS선택자")NodeList조건에 맞는 모든 요소
getElementsByClassName("cls")HTMLCollection클래스로 찾기(실시간 목록)
getElementsByTagName("p")HTMLCollection태그 이름으로 찾기
EXAMPLE
const title  = document.getElementById("title");
const first  = document.querySelector(".msg");        // class="msg" 첫 요소
const all    = document.querySelectorAll("ul li");    // ul 안 모든 li
const btn    = document.querySelector("#save-btn");   // # 은 id, . 은 class

// querySelectorAll 결과는 for...of 로 순회
for (const li of all) {
  console.log(li.textContent);
}
주의 — 찾는 요소가 없으면 getElementById·querySelector는 null을 반환합니다. 이 상태에서 null.textContent처럼 접근하면 오류가 납니다. 또한 <script>가 요소보다 위에 있으면 아직 만들어지지 않은 요소를 못 찾습니다 → 스크립트를 </body> 직전에 두거나 defer를 사용합니다.
✏️

내용 · 속성 · 스타일 바꾸기

가져온 요소를 실제로 수정한다

텍스트와 HTML 내용

EXAMPLE
const box = document.querySelector("#box");

box.textContent = "순수 텍스트로 교체";       // 태그는 글자 그대로 표시됨(안전)
box.innerHTML   = "<b>굵은</b> 글씨";        // HTML로 해석해서 삽입

const input = document.querySelector("#name");
console.log(input.value);   // 입력 요소의 값은 value 로 읽고 쓴다
input.value = "루크";
보안 — 사용자가 입력한 값을 innerHTML에 그대로 넣으면 악성 스크립트가 실행될 수 있습니다(XSS). 사용자 입력을 표시할 때는 textContent를 사용하세요.

속성(attribute)

EXAMPLE
const img = document.querySelector("img");

img.getAttribute("src");            // 속성 읽기
img.setAttribute("src", "b.png");   // 속성 쓰기
img.setAttribute("alt", "설명");
img.removeAttribute("width");       // 속성 삭제

// 자주 쓰는 속성은 . 으로 바로 접근 가능
img.src = "c.png";
const link = document.querySelector("a");
link.href = "https://yu.ac.kr";

클래스와 스타일

EXAMPLE
const menu = document.querySelector("#menu");

menu.classList.add("active");        // 클래스 추가
menu.classList.remove("hidden");     // 클래스 제거
menu.classList.toggle("open");       // 있으면 제거, 없으면 추가
menu.classList.contains("active");   // 포함 여부 true / false

// 인라인 스타일 직접 지정 (CSS 속성은 camelCase)
menu.style.color = "#1E3A5F";
menu.style.backgroundColor = "#F5EFE7";
menu.style.display = "none";
스타일을 여러 개 바꿔야 할 때는 style을 하나씩 지정하기보다, CSS에 클래스를 미리 정의해 두고 classList.add/remove로 전환하는 방식이 더 깔끔합니다.

노드 생성 · 추가 · 삭제

트리에 새 가지를 붙이고 잘라낸다
EXAMPLE — 목록에 항목 추가
const ul = document.querySelector("#todo");

// 1) 요소 만들기
const li = document.createElement("li");

// 2) 내용·속성 채우기
li.textContent = "자바스크립트 복습";
li.classList.add("item");

// 3) 트리에 붙이기
ul.appendChild(li);          // 맨 뒤에 추가
ul.prepend(li);              // 맨 앞에 추가
ul.insertBefore(li, ul.firstElementChild); // 특정 요소 앞에
EXAMPLE — 삭제
const item = document.querySelector(".item");

item.remove();                 // 자기 자신을 트리에서 제거
ul.removeChild(ul.lastElementChild); // 부모가 자식을 제거

// 안의 내용 전부 비우기
ul.innerHTML = "";
메서드하는 일
document.createElement(tag)새 요소 노드 생성
parent.appendChild(node) / append()자식으로 맨 뒤에 추가
parent.prepend(node)자식으로 맨 앞에 추가
node.remove()해당 노드 삭제
node.cloneNode(true)노드 복제(하위 포함)

이벤트 다루기

사용자의 동작에 반응한다

클릭·입력·스크롤 같은 사용자 동작을 이벤트라고 합니다. addEventListener로 "이 요소에서 이 이벤트가 일어나면 이 함수를 실행하라"고 등록합니다.

EXAMPLE
const btn = document.querySelector("#save-btn");

btn.addEventListener("click", function (event) {
  console.log("버튼이 클릭됨");
  console.log(event.target);   // 이벤트가 일어난 요소
});

// 입력값이 바뀔 때마다
const input = document.querySelector("#search");
input.addEventListener("input", function () {
  console.log("현재 입력값:", input.value);
});

// 폼 제출 시 기본 동작(새로고침) 막기
const form = document.querySelector("form");
form.addEventListener("submit", function (e) {
  e.preventDefault();
  console.log("검증 후 직접 처리");
});
이벤트발생 시점
click요소를 클릭했을 때
input / change입력값이 바뀔 때 / 바뀌고 포커스가 떠날 때
submit폼이 제출될 때
keydown / keyup키를 누를 때 / 뗄 때
mouseover / mouseout마우스가 요소에 올라올 때 / 벗어날 때
DOMContentLoadedHTML 파싱이 끝났을 때(document에 등록)

이벤트 객체 event

  • event.target — 실제로 이벤트가 발생한 요소
  • event.preventDefault() — 기본 동작 취소(링크 이동, 폼 전송 등)
  • event.stopPropagation() — 이벤트가 부모로 전파되는 것을 중단
  • event.key — 키보드 이벤트에서 누른 키 이름 ("Enter", "a" 등)
흐름 정리 — ① querySelector로 요소를 찾고 → ② addEventListener로 이벤트를 등록하고 → ③ 콜백 함수 안에서 textContent·classList·createElement 등으로 DOM을 바꾼다. 대부분의 웹 인터랙션이 이 세 단계입니다.

정리 & 실습 문제

직접 손으로 확인해 봅니다
1
BOM은 창, DOM은 문서
window가 최상위이고 document는 그 하위에서 페이지 내용을 담당한다
2
선택 → 수정 → 반응
querySelector로 찾고, textContent/classList로 바꾸고, addEventListener로 이벤트에 연결한다
3
스크립트 위치와 null 체크
스크립트는 </body> 직전에 두거나 defer, 선택 결과가 null일 수 있음에 주의
