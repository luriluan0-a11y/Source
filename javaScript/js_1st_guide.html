자바스크립트 식별자

변수·상수·함수의 이름을 정하는 규칙

식별자(identifier)는 변수, 상수(리터럴), 함수 등에 붙이는 이름입니다. 아무렇게나 지을 수 있는 것이 아니라 정해진 규칙을 따라야 합니다.

식별자 작성 규칙

1
첫 번째 문자
알파벳(A-Z, a-z), 언더스코어(_), 달러 기호($)만 사용 가능
2
두 번째 이후 문자
알파벳, 언더스코어, 숫자(0-9), 달러 기호 사용 가능
3
대소문자 구분
myHome과 myhome은 서로 다른 식별자로 취급됩니다
4
예약어 사용 불가
false, for, if, null 등 자바스크립트 예약어는 식별자로 쓸 수 없습니다

식별자 사용 사례

EXAMPLE
6variable;      // (X) 숫자로 시작할 수 없음
student_ID;     // (O)
_code;          // (O) 문법적으로는 맞지만 관례상 권장하지 않음
if;             // (X) 예약어 if는 사용 불가
%calc;          // (X) % 기호는 사용 불가
bar, Bar;       // (O) bar와 Bar는 서로 다른 식별자임에 주의
실무 팁 — 언더스코어로 시작하는 이름(_code)은 문법적으로 허용되지만, 보통 "내부에서만 쓰는 값"이라는 관례적 표시로 사용됩니다. 특별한 이유가 없다면 일반 변수명을 쓰는 것이 좋습니다.
📝

자바스크립트 문장

세미콜론(;)으로 문장을 구분한다

자바스크립트 프로그램은 문장(statement) 단위로 구성됩니다. 문장과 문장을 구분할 때 세미콜론(;)을 사용합니다.

EXAMPLE
i = i + 1              // (O) 한 줄에 한 문장만 있으면 세미콜론 생략 가능
j = j + 1;             // (O)
k = k + 1; m = m + 1;  // (O) 한 줄에 여러 문장을 쓸 때는 세미콜론으로 구분
n = n + 1  p = p + 1;  // (X) 첫 번째 문장 끝에 세미콜론이 필요함
한 줄에 한 문장만 쓸 경우 세미콜론은 생략할 수 있지만, 습관적으로 세미콜론을 붙이는 것을 권장합니다. 특히 한 줄에 여러 문장을 쓸 때는 세미콜론이 반드시 필요합니다.

주석문

주석은 코드에 설명을 남기거나 실행되지 않게 잠시 막아둘 때 사용합니다. 실행에는 영향을 주지 않습니다.

EXAMPLE
// 한 줄 주석. 라인의 끝까지 주석 처리됩니다.

/*
   여러 줄 주석은 슬래시-별표로 시작해서
   별표-슬래시로 끝납니다.
*/

데이터 타입

자바스크립트가 다루는 값의 종류

자바스크립트에서 다루는 데이터의 종류는 크게 다섯 가지입니다.

타입설명예시
숫자(Number)정수와 실수를 구분하지 않고 하나의 타입으로 다룹니다42, 3.14
논리(Boolean)참/거짓 두 가지 값만 가집니다true, false
문자열(String)따옴표로 감싼 문자의 나열입니다'좋은 세상', "365"
객체 레퍼런스객체를 가리키는 참조값 (C 언어의 포인터와 유사){ name: '루크' }
null값이 없음을 표시하는 특수 키워드null
주의 — 자바스크립트에는 C나 Java에 있는 "문자(character)" 타입이 따로 없습니다. "a"처럼 글자 하나도 문자열 타입으로 취급됩니다.
🧮

변수

데이터를 저장하는 공간

변수는 자바스크립트에서 데이터를 저장하는 공간입니다. 변수를 선언한다는 것은 변수의 이름을 정하고, 그 이름으로 데이터를 담을 저장 공간을 확보하는 것을 의미합니다.

변수 선언 방법: var, let, const

var

가장 오래된 선언 방식입니다. 같은 이름으로 재선언·재할당이 모두 가능하고, 범위(scope) 규칙이 느슨해 예상치 못한 오류가 생기기 쉽습니다. 요즘은 잘 사용하지 않습니다.

let

값을 바꿀 수 있는 변수를 선언할 때 사용합니다. 같은 이름으로 재선언은 불가능하지만, 재할당(값 변경)은 가능합니다.

const

값이 변하지 않는 상수를 선언할 때 사용합니다. 선언과 동시에 값을 반드시 초기화해야 하며, 이후 재할당이 불가능합니다.

EXAMPLE
let score = 0;         // 값이 바뀔 수 있는 변수
score = 10;            // 재할당 가능

const PI = 3.14;        // 값이 고정된 상수
PI = 3.141592;          // (X) 오류 발생: const는 재할당 불가
기본 원칙은 가급적 const를 사용하고, 값이 바뀌어야 할 때만 let을 사용하는 것입니다. var는 특별한 이유가 없다면 사용하지 않습니다.
🔀

조건문

조건에 따라 실행 흐름을 분기한다

조건문은 주어진 조건이 참인지 거짓인지에 따라 서로 다른 코드를 실행합니다.

if문 / if-else문

EXAMPLE
let hp = 30;

if (hp <= 0) {
  console.log("게임 오버");
} else if (hp < 50) {
  console.log("체력이 위험합니다");
} else {
  console.log("체력이 충분합니다");
}

switch문

하나의 값을 여러 경우와 비교해서 분기가 많을 때는 switch문이 if-else보다 읽기 편합니다.

EXAMPLE
let stage = 2;

switch (stage) {
  case 1:
    console.log("튜토리얼");
    break;
  case 2:
    console.log("초급 던전");
    break;
  default:
    console.log("알 수 없는 스테이지");
}
주의 — switch문에서 break를 빠뜨리면 아래 case문이 조건과 상관없이 계속 실행됩니다(fall-through). 각 case가 끝날 때 break를 잊지 않아야 합니다.
🔁

반복문

같은 코드를 여러 번 반복 실행한다

반복문은 조건이 만족되는 동안 같은 코드 블록을 반복해서 실행합니다.

for문

반복 횟수가 정해져 있을 때 가장 많이 사용합니다.

EXAMPLE
// 초기값; 조건식; 증감식
for (let i = 0; i < 5; i++) {
  console.log("반복 " + i + "번째");
}

while문

조건을 먼저 검사하고, 조건이 참인 동안 반복합니다. 반복 횟수를 미리 알 수 없을 때 사용합니다.

EXAMPLE
let hp = 100;

while (hp > 0) {
  hp -= 20;
  console.log("남은 체력: " + hp);
}

do-while문

조건과 상관없이 코드 블록을 최소 한 번은 실행한 뒤 조건을 검사합니다.

EXAMPLE
let count = 0;

do {
  console.log("count: " + count);
  count++;
} while (count < 3);
for

반복 횟수가 정해진 경우

while

조건에 따라 반복 횟수가 유동적인 경우, 최소 0번 실행될 수 있음

do-while

조건과 무관하게 최소 1번은 반드시 실행해야 하는 경우

⛔

break문과 continue문

반복문의 흐름을 제어한다

break — 반복을 즉시 종료

EXAMPLE
for (let i = 0; i < 10; i++) {
  if (i === 5) {
    break;  // i가 5가 되는 순간 반복문을 완전히 빠져나감
  }
  console.log(i);
}
// 출력: 0 1 2 3 4

continue — 이번 반복만 건너뛰기

EXAMPLE
for (let i = 0; i < 5; i++) {
  if (i === 2) {
    continue;  // i가 2일 때만 건너뛰고 다음 반복으로 이동
  }
  console.log(i);
}
// 출력: 0 1 3 4
break는 반복문 자체를 끝내고, continue는 현재 반복만 건너뛰고 다음 반복으로 넘어갑니다. 둘의 차이를 헷갈리지 않도록 주의합니다.
