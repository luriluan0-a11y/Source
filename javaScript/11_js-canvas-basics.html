1. 캔버스란?

<canvas>는 웹 페이지 안에 놓는 빈 도화지입니다. HTML은 도화지만 만들어 주고, 실제 그림은 JavaScript가 그립니다.

기본 구조

<canvas id="myCanvas" width="400" height="250"></canvas>

<script>
  const canvas = document.getElementById("myCanvas"); // 1. 도화지를 찾는다
  const ctx = canvas.getContext("2d");                 // 2. 붓(그리기 도구)을 꺼낸다
  ctx.fillRect(20, 20, 100, 60);                        // 3. 그린다
</script>
이름뜻
canvas도화지. 크기(width, height)를 가진다
ctx (context)붓과 물감 세트. 색, 선 굵기, 그리기 명령이 모두 여기에 있다
getContext("2d")2D 그림용 도구를 꺼내는 명령
기억하기: 캔버스 크기는 CSS가 아니라 width, height 속성으로 정합니다. CSS로만 크기를 바꾸면 그림이 늘어나 흐릿해집니다.

아래 실습 상자의 왼쪽 코드를 바꾸고 실행을 눌러 보세요. 코드 안에서는 canvas와 ctx를 이미 쓸 수 있게 준비해 두었습니다.

2. 캔버스의 좌표

캔버스의 좌표는 수학 시간의 좌표와 조금 다릅니다.

  • 원점 (0, 0)은 왼쪽 위 모서리입니다.
  • x는 오른쪽으로 갈수록 커집니다.
  • y는 아래로 갈수록 커집니다. (수학과 반대)
  • 단위는 픽셀(px)입니다.

3. 사각형 그리기

사각형은 명령 하나로 바로 그릴 수 있는 유일한 도형입니다.

명령하는 일
fillRect(x, y, w, h)속이 채워진 사각형
strokeRect(x, y, w, h)테두리만 있는 사각형
clearRect(x, y, w, h)그 영역을 지운다 (투명하게)
속성뜻예
fillStyle채우기 색"red", "#2e6da4", "rgb(46,109,164)"
strokeStyle선 색"#1a3a5c"
lineWidth선 굵기(px)4
색을 먼저 정하고 그 다음에 그립니다. 붓에 물감을 먼저 묻히는 것과 같습니다. 한 번 정한 색은 바꾸기 전까지 계속 쓰입니다.

4. 선과 경로(Path)

사각형이 아닌 도형은 경로로 그립니다. 연필을 종이에 대고 움직이는 순서를 말로 적는다고 생각하면 됩니다.

  1. beginPath() : 새 그림을 시작한다 (이전 경로와 분리)
  2. moveTo(x, y) : 연필을 들어서 이 점으로 옮긴다
  3. lineTo(x, y) : 지금 점에서 이 점까지 선을 긋는다
  4. closePath() : 시작점으로 돌아가 도형을 닫는다 (선택)
  5. stroke() 또는 fill() : 실제로 화면에 그린다
중요: lineTo까지만 쓰면 화면에 아무것도 안 보입니다. 마지막에 stroke()나 fill()을 꼭 불러야 합니다.

5. 원 그리기

원은 arc()로 그립니다.

ctx.arc(x, y, 반지름, 시작각, 끝각);
  • x, y는 원의 중심입니다. (사각형은 왼쪽 위 모서리였던 것과 다릅니다)
  • 각도는 도(°)가 아니라 라디안을 씁니다. 한 바퀴(360°)는 Math.PI * 2입니다.
  • 각도 0은 원의 오른쪽(3시 방향)이고, 시계 방향으로 커집니다.
도(°)90°180°270°360°
라디안Math.PI / 2Math.PIMath.PI * 1.5Math.PI * 2

6. 글자 쓰기

명령·속성하는 일
font글꼴과 크기. CSS와 같은 형식 ("bold 24px sans-serif")
fillText(글자, x, y)채운 글자
strokeText(글자, x, y)테두리 글자
textAlign"left", "center", "right" : x 기준을 어디로 둘지
글자의 y는 글자 위쪽이 아니라 밑줄(기준선) 위치입니다. y를 0으로 두면 글자가 위로 잘려 보이지 않습니다.

7. 애니메이션

캔버스 그림은 한 번 그리면 움직이지 않습니다. 움직이는 것처럼 보이게 하려면 "지우고 → 조금 옮겨서 → 다시 그리기"를 아주 빠르게 반복합니다. 만화책 넘기기와 같은 원리입니다.

function draw() {
  ctx.clearRect(0, 0, canvas.width, canvas.height); // 1. 전부 지운다
  x = x + 2;                                        // 2. 위치를 바꾼다
  ctx.fillRect(x, 50, 40, 40);                      // 3. 다시 그린다
  requestAnimationFrame(draw);                      // 4. 다음 화면에서 또 부른다
}
draw();
  • requestAnimationFrame(함수)는 브라우저가 다음 화면을 그릴 때(보통 1초에 60번) 함수를 불러 줍니다.
  • setInterval보다 부드럽고, 탭을 안 보고 있을 때는 알아서 쉬어서 효율적입니다.

아래는 벽에 닿으면 튕기는 공입니다. dx, dy(속도)나 r(반지름)을 바꿔 보세요.

clearRect 줄을 지우고 실행해 보세요. 이전 그림이 지워지지 않아 공이 지나간 자국이 남습니다. 애니메이션에서 "지우기"가 왜 필요한지 알 수 있습니다.

8. 마우스로 그리기

캔버스에 이벤트를 붙이면 사용자의 클릭·움직임에 반응하는 그림을 만들 수 있습니다.

canvas.addEventListener("click", (e) => {
  const rect = canvas.getBoundingClientRect(); // 캔버스가 화면 어디에 있는지
  const x = e.clientX - rect.left;             // 화면 좌표 → 캔버스 좌표
  const y = e.clientY - rect.top;
});
e.clientX는 브라우저 화면 기준 좌표입니다. 캔버스 안의 좌표로 바꾸려면 캔버스의 위치(rect.left, rect.top)를 빼야 합니다.

아래 캔버스를 클릭하면 원이 찍히고, 마우스를 누른 채 끌면 선이 그려집니다.

9. 자주 하는 실수

증상원인해결
아무것도 안 보인다 lineTo, arc만 쓰고 stroke()/fill()을 안 불렀다 경로 끝에 stroke() 또는 fill() 추가
도형끼리 선으로 이어진다 / 색이 같이 바뀐다 새 도형을 그릴 때 beginPath()를 빼먹었다 도형마다 beginPath()로 시작
Cannot read properties of null (reading 'getContext') HTML에 캔버스가 만들어지기 전에 스크립트가 실행됐다, 또는 id 오타 <script>를 </body> 바로 앞에 두고 id 확인

10. 연습 문제

아래 빈 캔버스에서 직접 풀어 보세요. 막히면 위의 예제를 참고합니다.

  1. 신호등: 세로로 긴 남색 사각형 안에 빨강·노랑·초록 원 3개를 그린다.
  2. 별 대신 오각형: moveTo와 lineTo로 오각형을 그리고 주황색으로 채운다.

  4. 움직이는 글자: 글자가 왼쪽에서 오른쪽으로 움직이다가 끝에 닿으면 다시 왼쪽에서 나오게 한다.
  5. 도전: 클릭할 때마다 원의 색이 무작위로 바뀌게 한다. (힌트: `hsl(${Math.random() * 360}, 50%, 50%)`)
