캔버스에 이미지 그리기

보노보노와 폰데라이온은 arc()로 원을 하나씩 그렸다. 이번에는 사진 파일을 불러와 캔버스에 통째로 그리고, 자르고, 움직여 본다.

미리 알아야 할 것: getContext('2d'), arc()와 fill(), setInterval, 마우스 이벤트의 e.offsetX

오늘 배울 함수 하나

context.drawImage(이미지, x, y);

1기본 세 단계

  1. 이미지 객체 만들기let img = new Image();

    빈 그림 상자를 하나 만든다.

  2. 다 불러오면 할 일 정하기img.onload = function () {...}

    사진이 도착했을 때 그리도록 미리 적어 둔다.

  3. 파일 경로 넣기img.src = 'dog/dog01.png';

    이 줄에서 불러오기가 시작된다.

let canvas = document.getElementById('myCanvas');
let context = canvas.getContext('2d');

let img = new Image();
img.onload = function () {
    context.drawImage(img, 0, 0);
};
img.src = 'dog/dog01.png';

실행 결과 (캔버스 400 × 300)

사진은 500 × 250인데 캔버스는 가로가 400이라, 캔버스 밖으로 나간 오른쪽 100픽셀이 잘렸다. 크기를 맞추는 방법은 3장에서 다룬다.

전체 코드 (이 파일과 같은 폴더에 저장해서 실행) 
<!DOCTYPE html>
<html lang="ko">
<head>
    <meta charset="UTF-8">
    <title>캔버스에 이미지 그리기</title>
</head>
<body>
    <h3>캔버스에 이미지 그리기</h3>
    <hr>
    <canvas id="myCanvas" style="background-color:aliceblue"
        width="400" height="300"></canvas>
    <script>
        let canvas = document.getElementById('myCanvas');
        let context = canvas.getContext('2d');

        let img = new Image();
        img.onload = function () {
            context.drawImage(img, 0, 0);
        };
        img.src = 'dog/dog01.png';
    </script>
</body>
</html>

경로 'dog/dog01.png'는 "이 HTML 파일 옆에 있는 dog 폴더 안의 dog01.png"라는 뜻이다. 이 자료 폴더(08.canvasImage)에는 강아지 사진 5장이 담긴 dog 폴더가 들어 있으니, 새 HTML 파일을 이 폴더에 저장하면 사진이 보인다.

2왜 onload 안에서 그려야 하나

사진 파일은 코드보다 늦게 도착한다. 자바스크립트는 사진을 기다리지 않고 다음 줄로 넘어가기 때문에, src를 넣은 바로 다음 줄에서 그리면 아직 빈 상자를 그리게 된다. 오류도 나지 않고 그냥 아무것도 안 보인다.

잘못된 코드에서 일어나는 일

  1. img.src = 'dog/dog01.png';불러오기 시작
  2. context.drawImage(img, 0, 0);아직 사진이 없음. 아무것도 그려지지 않음
  3. 사진 도착그릴 코드는 이미 지나가 버렸다

onload를 쓴 코드

  1. img.onload = function () {...}"도착하면 이걸 해라"라고 적어 둠
  2. img.src = 'dog/dog01.png';불러오기 시작
  3. 사진 도착 → onload 함수 실행이때 drawImage가 실행되어 사진이 그려진다

onload를 src보다 먼저 적는 이유도 같다. 이미 한 번 불러온 사진은 아주 빨리 도착할 수 있어서, 할 일을 먼저 적어 두는 편이 안전하다.

3drawImage의 세 가지 형태

괄호 안에 숫자를 몇 개 넣느냐에 따라 하는 일이 달라진다.

숫자 2개
drawImage(img, x, y)

(x, y)에 원래 크기 그대로 그린다.

숫자 4개
drawImage(img, x, y, 너비, 높이)

(x, y)에 정한 크기로 늘이거나 줄여서 그린다.

숫자 8개
drawImage(img, sx, sy, sw, sh, x, y, 너비, 높이)

원본에서 (sx, sy)부터 sw × sh만큼 잘라 낸 조각을 캔버스의 (x, y)에 정한 크기로 그린다.

실습 A. 위치와 크기 (숫자 4개)

context.drawImage(img, 0, 0, 200, 100);

실습 B. 잘라서 그리기 (숫자 8개)

왼쪽 원본에서 빨간 틀 안만 잘라서, 오른쪽 캔버스 (0, 0)에 300 × 150 크기로 그린다. 작은 조각을 크게 그리면 확대가 된다.

원본 (빨간 틀 = 잘라 낼 부분)

결과 캔버스 300 × 150

context.drawImage(img, 180, 90, 180, 90, 0, 0, 300, 150);

앞의 네 숫자는 원본 사진 기준, 뒤의 네 숫자는 캔버스 기준이다. 이 둘을 헷갈리는 경우가 가장 많다.

4비율 지키기

너비와 높이를 아무렇게나 넣으면 사진이 납작해지거나 길쭉해진다. 너비를 정했다면 높이는 원본 비율로 계산한다. 원본 크기는 img.width, img.height에 들어 있다.

높이 = img.height * (너비 / img.width)

img.onload = function () {
    // 왼쪽: 200 × 200으로 억지로 맞춤
    context.drawImage(img, 0, 0, 200, 200);

    // 오른쪽: 너비 180, 높이는 계산
    let w = 180;
    let h = img.height * (w / img.width);
    context.drawImage(img, 210, 0, w, h);
};

왼쪽은 2:1 사진을 1:1로 눌러서 강아지가 좁아졌다. 오른쪽은 500 × 250을 180 × 90으로 줄여 비율이 그대로다.

5그리는 순서 = 쌓이는 순서

폰데라이온에서 얼굴을 갈기보다 나중에 그려야 얼굴이 위에 보였던 것처럼, 캔버스는 나중에 그린 것이 위에 덮인다. 사진 위에 글자나 도형을 올리려면 사진을 먼저 그린다.

6사진 바꾸기와 움직이기

캔버스의 그림은 한 번 그리면 지울 수 없는 물감과 같다. 화면을 바꾸려면 지우고(clearRect) → 다시 그리기를 반복한다.

예제 1. 캔버스 슬라이드쇼

강아지 사진 배경 예제에서는 body 배경을 바꿨다. 같은 사진 5장을 캔버스에 1초마다 번갈아 그려 본다. 사진을 미리 다 불러 두는 것이 핵심이다.

let pics = [];
for (let i = 0; i < 5; i++) {
    pics[i] = new Image();
    pics[i].src = 'dog/dog0' + (i + 1) + '.png';
}

let j = 0;
let timer = null;

function nextPic() {
    context.clearRect(0, 0, 400, 200);
    context.drawImage(pics[j], 0, 0, 400, 200);
    j = j + 1;
    if(j >= pics.length){
        j = 0;
    }
}

btn.addEventListener('click', function () {
    if(timer == null){
        timer = setInterval(nextPic, 1000);
    }else{
        clearInterval(timer);
        timer = null;
    }
});
dog01.png

버튼 하나로 시작과 멈춤을 번갈아 하는 방식은 06의 숫자 세기 예제와 같다.

예제 2. 마우스를 따라다니는 사진

mousemove가 일어날 때마다 캔버스를 지우고, 포인터 위치에 작은 사진을 다시 그린다. 포인터가 사진 한가운데 오도록 너비와 높이의 절반씩 뺀다.

canvas.addEventListener('mousemove', function (e) {
    context.clearRect(0, 0, 400, 250);
    context.drawImage(img, e.offsetX - 50, e.offsetY - 25, 100, 50);
});

체크를 끄고 움직여 보자. 지우지 않으면 지나간 자리가 모두 남는다.

7자주 하는 실수

사진이 도착하기 전에 그리면 아무것도 보이지 않는다. (2장 참고)

잘못된 코드
img.src = 'dog/dog01.png';
context.drawImage(img, 0, 0);
올바른 코드
img.onload = function () {
    context.drawImage(img, 0, 0);
};
img.src = 'dog/dog01.png';

경로 문자열을 바로 넣을 수는 없다. drawImage에는 이미지 객체를 넘긴다.

잘못된 코드
context.drawImage('dog/dog01.png', 0, 0);
올바른 코드
context.drawImage(img, 0, 0);

Image는 대문자로 시작한다. 소문자로 쓰면 "image is not defined" 오류가 난다.

잘못된 코드
let img = new image();
올바른 코드
let img = new Image();

경로는 HTML 파일 위치 기준이다. 한 폴더 위로 올라가려면 ../를 붙인다. 확장자(.png, .jpg)와 대소문자도 정확히 맞춘다. 대소문자는 내 컴퓨터(Windows)에서는 달라도 열리지만, 웹 서버에 올리면 안 열리는 경우가 많다.

HTML은 day09 폴더, 사진은 day08/image 폴더에 있을 때
img.src = 'image/Dog01.PNG';
올바른 경로
img.src = '../day08/image/dog01.png';

캔버스 크기는 CSS가 아니라 width, height 속성으로 정한다. CSS로 키우면 작은 그림을 늘린 것이라 흐려진다.

잘못된 코드
<canvas id="myCanvas" style="width:800px; height:600px">
올바른 코드
<canvas id="myCanvas" width="800" height="600">

사진이 안 보이면 F12 개발자 도구의 Console 탭을 먼저 본다. 경로가 틀렸으면 "ERR_FILE_NOT_FOUND"처럼 파일을 찾지 못했다는 메시지가 뜬다.

8연습 문제

  1. 가운데에 반 크기로

    400 × 300 캔버스 정가운데에 dog03.png를 원래 크기의 절반(250 × 125)으로 그려 보자.

    힌트: x = (캔버스 너비 - 그림 너비) / 2

  2. 코만 크게

    dog01.png에서 강아지 코 부분만 잘라 캔버스 가득 확대해 보자. 실습 B로 좌표를 먼저 찾아도 된다.

    사용할 것: 숫자 8개짜리 drawImage

  3. 사진에 이름표 달기

    사진 아래쪽에 검은 띠를 깔고 흰 글자로 강아지 이름을 써 보자.

    사용할 것: drawImage → fillRect → fillText 순서

  4. 버튼으로 넘기기

    "이전", "다음" 버튼을 만들어 강아지 사진 5장을 한 장씩 넘겨 보자. 첫 장에서 이전을 누르면 마지막 장으로 간다.

    사용할 것: 이미지 배열, click, clearRect

  5. 사진 도장 찍기

    캔버스를 클릭할 때마다 클릭한 자리에 작은 강아지 사진이 찍히게 해 보자. 이번에는 지우지 않는다.

    사용할 것: click, e.offsetX, e.offsetY
