마우스 이벤트

사용자가 마우스로 한 행동(누르기, 움직이기, 올리기)에 맞춰 함수를 실행하는 방법을 배운다.

미리 알아야 할 것: getElementById, addEventListener, style 속성 바꾸기

지금 포인터 위치

clientX-
clientY-

이 숫자도 mousemove 이벤트로 바뀐다. 실습은 마우스가 있는 컴퓨터에서 해 보자.

1기본 형태

요소.addEventListener('이벤트이름', function () {
    // 이벤트가 일어날 때 실행할 코드
});

아래 코드는 "버튼을 클릭하면 영역의 배경을 노란색으로 바꿔라"라는 뜻이다.

let btn = document.getElementById('btn');
let stage = document.getElementById('stage');

btn.addEventListener('click', function () {
    stage.style.backgroundColor = 'yellow';
});

2마우스 이벤트 종류

빨간 테두리 상자 위에서 마우스를 움직이고, 누르고, 더블클릭해 보자. 일어난 이벤트의 줄이 칠해지고 횟수가 올라간다.

이벤트 시험 상자

회색 부분은
자식 요소

이 상자에서는 오른쪽 클릭 메뉴가 뜨지 않게 막아 두었다.

이벤트 언제 일어나는가 자주 쓰는 곳 횟수
click왼쪽 버튼을 눌렀다 뗐을 때버튼, 메뉴0
dblclick빠르게 두 번 클릭했을 때글 수정 모드로 전환0
mousedown버튼을 누르는 순간드래그 시작0
mouseup버튼을 떼는 순간드래그 끝0
mousemove요소 위에서 포인터가 움직일 때마다좌표 표시, 따라다니는 효과0
mouseover포인터가 요소나 그 자식 위로 들어올 때색 바꾸기0
mouseout포인터가 요소나 그 자식에서 나갈 때색 되돌리기0
mouseenter포인터가 요소 영역 안으로 들어올 때 (자식 사이 이동은 무시)드롭다운 메뉴 열기0
mouseleave포인터가 요소 영역 밖으로 나갈 때 (자식 사이 이동은 무시)드롭다운 메뉴 닫기0
contextmenu오른쪽 버튼으로 메뉴를 열 때나만의 메뉴 만들기0

3이벤트가 일어나는 순서

한 번의 동작에도 이벤트는 여러 개 일어난다.

클릭 한 번mousedown → mouseup → click
더블클릭mousedown → mouseup → click → mousedown → mouseup → click → dblclick
요소 위를 지나갈 때mouseover → mouseenter → mousemove(여러 번) → mouseout → mouseleave

click이 먼저 두 번 일어난 뒤 dblclick이 일어난다. 그래서 한 요소에 click과 dblclick을 함께 걸면, 더블클릭할 때 click 함수도 두 번 실행된다.

직접 해 보기

    연속으로 일어난 mousemove는 한 칸에 횟수로 묶어 보여 준다.

    콘솔에서 확인하는 전체 코드 
    <!DOCTYPE html>
<html lang="ko">
<head>
    <meta charset="UTF-8">
    <title>이벤트 순서 확인</title>
    <script>
        window.onload = function () {
            let btn = document.getElementById('btn');
            let names = ['mousedown', 'mouseup', 'click', 'dblclick'];

            for (let i = 0; i < names.length; i++) {
                btn.addEventListener(names[i], function () {
                    console.log(names[i]);
                });
            }
        }
    </script>
</head>
<body>
    <button id="btn">클릭해 보세요</button>
</body>
</html>

    실행한 뒤 개발자 도구(F12)의 Console 탭을 본다.

    4이벤트 객체: 어디를 어떻게 눌렀는지 알아내기

    함수에 매개변수를 하나 적으면 브라우저가 이벤트 정보를 담아서 넘겨준다. 이름은 보통 e 또는 event로 쓴다.

    box.addEventListener('click', function (e) {
    console.log(e.clientX, e.clientY);
});

    직접 확인하기

    자식 요소

    회색 자식 요소 위로 옮기면 offsetX의 기준과 target이 바뀐다. 페이지를 스크롤한 뒤에는 clientY와 pageY를 비교해 보자. Shift나 Ctrl을 누른 채 움직여도 된다.

    e.clientX, Y
    -
    e.pageX, Y
    -
    e.offsetX, Y
    -
    e.button
    -
    e.target
    -
    e.currentTarget
    -
    e.shiftKey
    -
    e.ctrlKey
    -
    e.altKey
    -

    좌표

    속성기준설명
    e.clientX, e.clientY브라우저 화면스크롤해도 화면 왼쪽 위가 (0, 0)
    e.pageX, e.pageY문서 전체스크롤한 만큼 값이 커진다
    e.offsetX, e.offsetY이벤트가 일어난 요소그 요소의 왼쪽 위가 (0, 0)

    그 밖에 자주 쓰는 정보

    속성값
    e.button누른 버튼. 0 왼쪽, 1 가운데(휠), 2 오른쪽
    e.target실제로 이벤트가 일어난 요소
    e.currentTarget이벤트를 걸어 둔 요소
    e.shiftKey, e.ctrlKey, e.altKey해당 키를 함께 눌렀으면 true

    e.button은 mousedown, mouseup에서 사용한다. click은 왼쪽 버튼에서만 일어나므로 버튼을 구분할 필요가 없다.

    브라우저 기본 동작 막기: e.preventDefault()

    오른쪽 클릭 메뉴처럼 브라우저가 원래 하던 동작을 막는다.

    box.addEventListener('contextmenu', function (e) {
    e.preventDefault();
    box.innerHTML = '오른쪽 클릭!';
});

    5mouseover와 mouseenter의 차이

    자식 요소가 없으면 두 이벤트는 똑같이 보인다. 차이는 자식 요소가 있을 때 드러난다.

    구분mouseover / mouseoutmouseenter / mouseleave
    자식 요소로 옮겨 갈 때다시 일어난다일어나지 않는다
    쓰면 좋은 경우어느 자식 위에 있는지 알아야 할 때영역에 들어오고 나간 것만 알면 될 때

    포인터를 바깥 → 회색 상자 → 검은 자식 요소 → 회색 상자 순서로 옮기면 mouseover는 3번, mouseenter는 1번 센다.

    직접 해 보기

    자식 요소
    0mouseover
    0mouseenter
    비교 예제 전체 코드 
    <!DOCTYPE html>
<html lang="ko">
<head>
    <meta charset="UTF-8">
    <title>mouseover와 mouseenter 비교</title>
    <style>
        #parent {
            background-color: lightgray;
            width: 300px;
            padding: 40px;
        }
        #child {
            background-color: skyblue;
        }
    </style>
    <script>
        window.onload = function () {
            let parent = document.getElementById('parent');
            let overText = document.getElementById('overText');
            let enterText = document.getElementById('enterText');
            let overCount = 0;
            let enterCount = 0;

            parent.addEventListener('mouseover', function () {
                overCount = overCount + 1;
                overText.innerHTML = overCount;
            });

            parent.addEventListener('mouseenter', function () {
                enterCount = enterCount + 1;
                enterText.innerHTML = enterCount;
            });
        }
    </script>
</head>
<body>
    <div id="parent">
        <span id="child">자식 요소</span>
    </div>
    <p>mouseover: <span id="overText">0</span>번</p>
    <p>mouseenter: <span id="enterText">0</span>번</p>
</body>
</html>

    6활용 예제

    예제 1. 마우스를 올리는 동안만 실행하기

    mouseover에서 타이머를 시작하고 mouseout에서 멈춘다. 전체 코드는 mouseover-rainbow.html에 있다.

    title.addEventListener('mouseover', function () {
    timer = setInterval(function () {
        // 0.3초마다 배경색 바꾸기
    }, 300);
});

title.addEventListener('mouseout', function () {
    clearInterval(timer);
});

    위 띠에 마우스를 올려 보자. 빼면 그 색에서 멈춘다.

    예제 2. 마우스 좌표 표시하기

    document에 이벤트를 걸면 화면 어디에서 움직여도 함수가 실행된다. 이 페이지 맨 위의 "지금 포인터 위치"도 같은 방법으로 만들었다.

    <!DOCTYPE html>
<html lang="ko">
<head>
    <meta charset="UTF-8">
    <title>마우스 좌표</title>
    <script>
        window.onload = function () {
            let result = document.getElementById('result');

            document.addEventListener('mousemove', function (e) {
                result.innerHTML = 'X: ' + e.clientX + ', Y: ' + e.clientY;
            });
        }
    </script>
</head>
<body>
    <p id="result">마우스를 움직여 보세요.</p>
</body>
</html>

    예제 3. 상자 드래그하기

    세 이벤트가 역할을 나눈다.

    1. mousedown: 드래그를 시작한다. 상자 안에서 어디를 잡았는지 기억한다.
    2. mousemove: 드래그 중이면 상자를 포인터 위치로 옮긴다.
    3. mouseup: 드래그를 끝낸다.

    직접 해 보기

    이 실습의 상자는 테두리 밖으로 나가지 않게 제한해 두었다. 아래 전체 코드에는 제한이 없고, 연습 문제 4번에서 직접 넣어 본다.

    mousemove와 mouseup을 document에 건 이유: 포인터를 빠르게 움직이면 상자 밖으로 벗어날 수 있다. box에 걸면 그 순간 이벤트를 받지 못해 상자가 멈추고, 상자 밖에서 버튼을 떼면 드래그가 끝나지 않는다.

    gapX, gapY가 필요한 이유: 이 값을 빼지 않으면 상자의 왼쪽 위 모서리가 포인터 위치로 순간 이동한다.

    드래그 예제 전체 코드 
    <!DOCTYPE html>
<html lang="ko">
<head>
    <meta charset="UTF-8">
    <title>상자 드래그</title>
    <style>
        #box {
            position: absolute;
            left: 50px;
            top: 50px;
            width: 100px;
            height: 100px;
            background-color: tomato;
            cursor: move;
        }
    </style>
    <script>
        window.onload = function () {
            let box = document.getElementById('box');
            let dragging = false;
            let gapX = 0;
            let gapY = 0;

            box.addEventListener('mousedown', function (e) {
                e.preventDefault(); // 드래그 중 글자가 선택되지 않게 한다
                dragging = true;
                gapX = e.clientX - box.offsetLeft;
                gapY = e.clientY - box.offsetTop;
            });

            document.addEventListener('mousemove', function (e) {
                if(dragging == true){
                    box.style.left = (e.clientX - gapX) + 'px';
                    box.style.top = (e.clientY - gapY) + 'px';
                }
            });

            document.addEventListener('mouseup', function () {
                dragging = false;
            });
        }
    </script>
</head>
<body>
    <div id="box"></div>
</body>
</html>

    7자주 하는 실수

    addEventListener에는 on을 붙이지 않는다.

    잘못된 코드
    btn.addEventListener('onclick', fn)
    올바른 코드
    btn.addEventListener('click', fn)

    ()를 붙이면 클릭하기 전에 바로 실행된다.

    잘못된 코드
    btn.addEventListener('click', fn())
    올바른 코드
    btn.addEventListener('click', fn)

    매개변수 e를 적지 않으면 이벤트 정보를 쓸 수 없다.

    잘못된 코드
    function () { console.log(e.clientX); }
    올바른 코드
    function (e) { console.log(e.clientX); }

    단위 px가 없으면 적용되지 않는다.

    잘못된 코드
    box.style.left = e.clientX;
    올바른 코드
    box.style.left = e.clientX + 'px';

    <head>의 스크립트에서 바로 찾으면 요소가 만들어지기 전이라 null이 된다.

    잘못된 코드
    let btn = document.getElementById('btn');
    올바른 코드
    window.onload = function () {
    let btn = document.getElementById('btn');
}
    • 터치 화면에는 "올리기"가 없다. 스마트폰에서는 mouseover에만 의존한 기능을 제대로 쓸 수 없으므로, 중요한 기능은 click으로도 쓸 수 있게 만든다.
    • 클릭할 대상은 가능하면 <button>으로 만든다. <button>은 키보드(Tab으로 이동, Enter나 Space로 실행)로도 click이 일어나지만, <div>는 그렇지 않다.

    8연습 문제

    1. 더블클릭 숨기기

      상자를 더블클릭하면 사라지게 만들어 보자.

      사용할 것: dblclick, style.display

    2. 버튼 구분하기

      상자를 왼쪽 버튼으로 누르면 빨간색, 오른쪽 버튼으로 누르면 파란색으로 바꿔 보자. 오른쪽 클릭 메뉴는 뜨지 않게 한다.

      사용할 것: mousedown, e.button, contextmenu, e.preventDefault()

    3. 따라다니는 원

      원이 마우스 포인터를 따라다니게 만들어 보자. 포인터가 원의 정중앙에 오도록 한다.

      사용할 것: mousemove, e.clientX, position: fixed

    4. 드래그 제한하기

      예제 3의 상자가 화면 왼쪽과 위쪽 밖으로 나가지 않게 고쳐 보자.

      사용할 것: if
