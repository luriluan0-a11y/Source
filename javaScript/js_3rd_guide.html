getElementsByClassName

클래스 이름으로 여러 요소를 한 번에 찾아오는 방법을 익힙니다

🎯

getElementsByClassName이란?

지정한 class 이름을 가진 요소를 모두 찾아오는 메서드

document.getElementsByClassName("클래스명")은 문서 안에서 해당 클래스가 붙은 모든 요소를 찾아 반환하는 메서드입니다. 지난주에 배운 getElementById가 요소 1개만 찾는 것과 달리, 클래스는 여러 요소에 중복해서 붙일 수 있으므로 결과도 여러 개가 될 수 있습니다.

핵심 — getElementsByClassName은 요소 하나가 아니라 목록(HTMLCollection)을 반환합니다. 그래서 메서드 이름도 Element가 아니라 Elements(복수형)입니다.
  • 대상: HTML 요소에 지정된 class 속성
  • 반환값: HTMLCollection (배열처럼 생겼지만 배열은 아닌 목록)
  • 일치 조건: 여러 클래스 중 하나라도 이름이 같으면 포함
  • 호출 대상: document 전체뿐 아니라 특정 요소에서도 호출 가능
📖

기본 문법

document 또는 특정 요소에서 호출한다
SYNTAX
document.getElementsByClassName("클래스명");

// 특정 요소 안에서만 찾을 수도 있다
부모요소.getElementsByClassName("클래스명");

// 여러 클래스를 동시에 만족하는 요소만 찾기 (공백으로 구분)
document.getElementsByClassName("클래스A 클래스B");
항목내용
매개변수찾고 싶은 클래스명 문자열 (공백으로 여러 개 지정 가능)
반환값HTMLCollection — 조건에 맞는 요소가 없으면 길이가 0인 빈 목록 (⚠️ null이 아님)
대소문자클래스명은 대소문자를 구분한다
class 속성이 없는 요소당연히 결과에 포함되지 않는다
참고 — getElementById는 결과가 없으면 null을 반환하지만, getElementsByClassName은 결과가 없어도 빈 HTMLCollection(길이 0)을 반환합니다. null 체크가 아니라 .length 체크로 존재 여부를 확인해야 합니다.
💡

예시로 확인하기

가져오기부터 순회, 값 바꾸기까지

예시 1 — 클래스로 요소 여러 개 가져오기

HTML
<ul>
  <li class="fruit">사과</li>
  <li class="fruit">바나나</li>
  <li class="veggie">당근</li>
  <li class="fruit">포도</li>
</ul>
JAVASCRIPT
const fruits = document.getElementsByClassName("fruit");

console.log(fruits);         // HTMLCollection(3) [li.fruit, li.fruit, li.fruit]
console.log(fruits.length);  // 3
console.log(fruits[0].textContent); // "사과" — 인덱스로 각 요소에 접근

예시 2 — 순회하면서 내용/스타일 바꾸기

JAVASCRIPT
const fruits = document.getElementsByClassName("fruit");

// HTMLCollection은 for...of 로 순회 가능
for (const item of fruits) {
  item.style.color = "#C47B1A";
  item.textContent = "🍎 " + item.textContent;
}

// 배열 메서드(forEach, map 등)를 쓰고 싶다면 배열로 변환
const fruitArray = Array.from(fruits);
fruitArray.forEach((item, i) => {
  console.log(i, item.textContent);
});
주의 — fruits.forEach(...)처럼 배열 메서드를 바로 호출하면 오류가 납니다. HTMLCollection은 배열이 아니라 "배열처럼 생긴(array-like)" 객체이기 때문입니다. forEach·map·filter 등을 쓰려면 Array.from(fruits)이나 [...fruits]로 먼저 배열로 바꿔야 합니다.

예시 3 — 특정 요소 안에서만 찾기

JAVASCRIPT
const box = document.getElementById("box");

// document 전체가 아니라 box 안에서만 .item 클래스를 찾는다
const itemsInBox = box.getElementsByClassName("item");
console.log(itemsInBox.length);

querySelectorAll과 비교

둘 다 여러 요소를 찾지만 결과의 성격이 다르다
구분getElementsByClassNamequerySelectorAll
반환 타입HTMLCollectionNodeList
실시간 반영(live)✅ DOM 변화가 자동 반영됨❌ 호출 시점 스냅샷(static), 이후 변화 반영 안 됨
선택자 문법클래스명만 가능모든 CSS 선택자 사용 가능 (#id, .class > p 등)
forEach 사용❌ 바로 안 됨 (배열 변환 필요)✅ 최신 브라우저에서 바로 가능
정리 — 단순히 클래스 하나로만 찾고, 목록이 실시간으로 갱신되길 원한다면 getElementsByClassName이 유용합니다. 복잡한 조건(자식 선택, 속성 선택 등)이 필요하거나 forEach를 바로 쓰고 싶다면 querySelectorAll이 더 편합니다.
⚠️

자주 하는 실수

이것만 기억하면 됩니다
1
배열이 아니라 HTMLCollection
.forEach(), .map() 등을 쓰려면 Array.from() 또는 [...컬렉션]으로 배열로 바꿔야 한다
2
실시간(live) 컬렉션이라는 점
한 번 가져온 결과도 DOM에 같은 클래스의 요소가 추가·삭제되면 .length와 내용이 자동으로 바뀐다
3
결과가 없어도 null이 아니다
일치하는 요소가 없으면 길이 0인 빈 HTMLCollection을 반환하므로, === null 체크는 의미가 없다
4
마침표(.)를 붙이지 않는다
querySelector(".fruit")와 달리 getElementsByClassName("fruit")은 클래스명만 순수하게 적는다

Q2. 다음 코드를 실행했을 때, 마지막 console.log(items.length)의 결과는?
HTML + JAVASCRIPT
<ul id="list">
  <li class="item">사과</li>
  <li class="item">바나나</li>
</ul>

<script>
  const items = document.getElementsByClassName("item");
  console.log(items.length); // ① 여기서는 2

  const li = document.createElement("li");
  li.className = "item";
  li.textContent = "포도";
  document.getElementById("list").appendChild(li);

  console.log(items.length); // ② 여기서는?
</script>
