# AI 이상형 월드컵 토너먼트 앱 만들기 — LLM Wiki

> 경기공유학교 2026 · 가족과 함께하는 AI 바이브코딩 (유한대학교)
> Day05 · 2026.07.30

## 1. 개요

가족 단위 참가자가 AI(바이브코딩)의 도움을 받아 **나만의 이상형 월드컵 토너먼트 게임**을
직접 기획하고, 그 기획서를 AI IDE(Antigravity)에 입력하여 실제 동작하는 웹 토너먼트 게임으로
완성하는 특강 세션. 코딩 경험이 없는 참가자도 "기획서 작성기" 웹앱에서 주제와 후보 아이템만 채우면
자동으로 마크다운 기획서가 만들어지고, 이를 AI에게 전달하여 게임을 즉시 생성하는 흐름이다.

## 2. 오늘의 목표

- 1:1 대결을 통해 최후의 1인을 가리는 이상형 월드컵 토너먼트 게임을 만든다.
- 음식, 애니메이션, 스포츠, 여행지 등 원하는 주제와 후보들을 직접 선정하고 배치해본다.
- 16강, 8강, 4강 등 라운드 진행과 VS 카드 연출, 승자 세레머니(폭죽) 및 최종 대진표(Bracket) 시각화를 경험한다.

## 3. 월드컵 토너먼트 특화 설계 규칙

1. **시각적 대립구도(VS 연출)**: 1대1 대결 화면에서 두 후보 카드 간의 흥미진진한 타격감 연출과 클릭 시 네온 이펙트를 부여한다.
2. **라운드 흐름 관리**: 16강 → 8강 → 4강 → 결승전으로 이어지는 대진표 셔플 및 진행율(Progress Bar) 표시.
3. **결과 및 세레머니**: 최후의 우승자 선택 시 대형 트로피 세레머니와 Canvas 폭죽(Confetti) 효과를 제공하고, 전체 랭킹 및 토너먼트 대진표(Bracket View)를 시각화한다.

## 4. 참고 주제 예시 (가족 추천 아이디어)

| 주제 | 주요 후보 예시 |
|---|---|
| K-푸드 대표 야식 | 치킨, 피자, 떡볶이, 족발, 삼겹살, 라면, 곱창, 햄버거 등 |
| 추억의 애니메이션 | 짱구는 못말려, 도라에몽, 명탐정 코난, 원피스, 드래곤볼, 포켓몬스터 등 |
| 가보고 싶은 세계 여행지 | 파리, 토쿄, 뉴욕, 발리, 하와이, 로마, 시드니, 런던 등 |
| 나의 최애 스낵/디저트 | 마카롱, 크로플, 빙수, 탕후루, 츄러스, 에그타르트, 젤라또, 소금빵 등 |

## 5. 폴더 구성

```
worldcupGame/
├─ worldcup_guide.html         # 특강 진행용 안내 페이지 (오늘의 목표/주제/규칙/순서)
├─ worldcup_paper.html         # 이상형 월드컵 "기획서 작성기" 웹앱
├─ 월드컵_게임_기획서.md        # 기획서 작성기로 만든 예시 기획서 (마크다운 결과물)
├─ worldcup_game.html          # 위 기획서를 AI가 구현한 완성 게임 (HTML 단일 페이지)
└─ LLM-wiki.md                 # 본 워크숍 종합 안내 위키 문서
```

## 6. 전체 제작 흐름 (참가자 관점)

1. **주제 및 후보 정하기** — 야식, 캐릭터, 여행지, 스포츠 등 원하는 토너먼트 주제 선정.
2. **기획서 작성기**(`worldcup_paper.html`)에서 원클릭 예시를 참고하여 후보 이름과 사진 URL, 설명을 입력.
3. 작성 완료 후 **마크다운 파일 다운로드** (`.md`).
4. **Antigravity IDE**를 열고 "마크다운 기획서를 읽고 html 단일 페이지로 월드컵 게임을 구현해줘." 라고 요청.
5. 완성된 **html 파일을 열어 가족과 함께 직접 플레이**해본다.

## 7. 기획서 작성기(`worldcup_paper.html`) 상세

바닐라 HTML/CSS/JS(프레임워크 없음, 단일 파일)로 구축된 폼 기반 도구.

### 7.1 주요 기능
- **예시대로 채우기 / 초기화**: 글쓰기가 막막한 초보자를 위해 원클릭으로 K-푸드 야식 월드컵 16강 데이터를 채움.
- **기본 정보**: 토너먼트 제목, 설명, 라운드 선택 (16강 / 8강 / 4강).
- **후보 카드 관리**: "+ 후보 추가" 버튼으로 후보 항목을 동적으로 추가/삭제. (후보명, 이미지 URL, 설명).
- **마크다운 다운로드**: 입력 데이터를 조합하여 `# 이상형 월드컵 게임 기획서` 형식의 `.md` 다운로드.

### 7.2 생성되는 마크다운의 고정 지시문
다운로드되는 마크다운 맨 위에는 항상 다음 지시문이 주석(`//`)으로 포함되어, AI IDE가 구현 방식을 일관되게 적용하도록 유도한다.

```markdown
// 게임의 구현 방법은 전달받은 후보 데이터 리스트를 바탕으로 토너먼트 대진표(16강/8강/4강)를 무작위 생성하고,
// 1대1 대결 화면(VS 카드)에서 선택 시 다음 라운드로 진행하는 방식이야.
// 최종 우승자 결정 시 Canvas 폭죽 이펙트와 우승 세레머니, 전체 순위표 및 토너먼트 대진표(Bracket)를 시각화해줘.
```

## 8. 예시 기획서 & 완성 게임: "K-푸드 대표 야식 월드컵 16강"

`worldcup_paper.html`의 "예시대로 채우기"로 생성된 기획서(`월드컵_게임_기획서.md`)를 AI가 구현한 결과물이 `worldcup_game.html`이다.

### 8.1 구현 구조 (`worldcup_game.html`)
단일 HTML 파일, 프레임워크 없이 순수 JS 및 CSS Canvas로 구현.

- **시작 화면**: 주제 타이틀, 라운드(16강/8강/4강) 선택 버튼, 전체 후보 모달.
- **매치 화면**:
  - 좌/우 후보 카드 (고화질 이미지, 명칭, 묘사, 선택 시 네온 발광 & 타격감 카드 틸트 애니메이션).
  - 중앙 VS 배지 및 진행률 프로그레스 바.
- **결과 화면**:
  - Canvas 폭죽 (Confetti) 파티클 애니메이션.
  - 우승 트로피 팝업 연출 & 2위/3위 순위표.
  - 전체 토너먼트 대진표(Bracket Tree) 시각화.
  - 다시하기(새 셔플) 및 결과 공유 기능.

## 9. 이 워크숍의 핵심 아이디어

- **기획서 작성 웹앱 → 마크다운 다운로드 → AI IDE 입력 → 실행 가능한 완성 게임 생성** 패턴 적용.
- 마크다운 내 **구현 제약 지시문 주석**을 통한 AI 생성 코드 품질 고도화.
- 초보자도 손쉽게 접근할 수 있도록 **원클릭 프리셋 및 시각적 대진표 시각화** 제공.
